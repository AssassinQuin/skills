# 开头-中间-结尾结构（三幕检查点）

## R — 原文 (Reading)

> "我们不妨看一看小说结构的开头、中间和结尾……开头：开门见山，引入主人公……中间：让主人公陷入一连串不可控的事件……结尾：让主人公对自己有更深刻的认知。"
>
> — 凯蒂·维兰德，第九章

---

## I — 方法论骨架 (Interpretation)

搭小说骨架，用**开头-中间-结尾**三幕检查点（不强制全用，按小说需求取舍）：

- **开头**：开门见山引入主人公、展示日常与标志性时刻、以动作开始、给读者在意他的理由、赋予愿望与目标、创造激发事件并迫使他回应。
- **中间**：让多米诺骨牌依次倒下、让最初目标渐行渐远、设新目标、让主人公由被动回应转为全面对抗。
- **结尾**：深化自我认知、极限考验、最后一刻赋予力量、成长为英雄、以独特方式击败反派、实现目标、以经典语句作结。

三幕之外，还要为骨架添加**血肉**——三大基本元素：幽默（拉近距离、调和黑色）、动作（推动情节）、关系（小说核心）。并用**首尾呼应**：开头引入的意象/场景/主题，结尾呼应，让小说更紧凑、线索更缜密。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 三本书的"三大元素"共通处
- **问题**: 作者随机抽三本风格迥异的小说（历史/科幻），找共通之处。
- **方法论的使用**: 发现都有关系、动作、幽默感。
- **结论**: 三大元素是读者翻页的根本动力。
- **结果**: 提纲阶段要有意融入。

### 案例 2: 《彼得潘》《爱国者》的首尾呼应
- **问题**: 如何让故事闭合得更圆满？
- **方法论的使用**: 开头引入的句子/农场，结尾经细微变换重现。
- **结论**: 强化连贯与主题，给结局画上句号。
- **结果**: 结尾更感人，线索更缜密。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户故事中间拖沓，读者流失。
2. 用户不知道开头怎么写、结尾怎么收。
3. 用户写完整本书，觉得结构松散、不连贯。
4. 用户想给故事"有头有尾"的闭环感。

### 语言信号

## E — 可执行步骤 (Execution)

1. **按开头清单搭第一幕**（引入主人公/展示日常/动作开始/赋予愿望/激发事件）。
   - 完成标准: 开头清单逐条核对，关键项（主人公、愿望、激发事件）齐备。

2. **按中间清单搭第二幕**（多米诺失控/目标渐远/设新目标/被动转对抗）。
   - 完成标准: 中间有"目标渐远 + 新目标 + 对抗升级"的递进。

3. **按结尾清单搭第三幕**（自我认知/极限考验/最后一刻力量/成长为英雄/经典语句作结）。
   - 完成标准: 结尾有精神蜕变 + 行动上的胜利 + 一句可记的收尾。

4. **融入三大元素 + 首尾呼应**。
   - 完成标准: 幽默/动作/关系都出现，开头与结尾有呼应意象/主题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 实验性/群像/散文式作品，无传统三幕结构——不强套。
- 用户只问某个具体节点（用 inciting-event / reverse-outline 等更聚焦的 skill）。

### 作者在书中警告的失败模式

- **开头倾倒苦难**：一开始把苦难挫折抖完，结尾无墨可写。
- **结尾轻易获胜**：让主人公轻易赢，读者不会揪心。

### 作者的盲点 / 时代局限

- "三幕结构"是西方叙事范式，网文（超长连载）结构更接近"单元爽点 + 卷级高潮"的循环，需将三幕映射到"单卷"而非"全书"。

### 容易混淆的邻近方法论

- 与"章节切分"的区分: 三幕是宏观骨架，章节切分（condense-outline 里）是微观节奏。
