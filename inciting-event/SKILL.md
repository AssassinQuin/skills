# 激发事件（那扇回不去的门）

## R — 原文 (Reading)

> "关键是要问自己，主人公能否从情节中顺利脱身，继续过他从前的安稳生活？如果答案是肯定的，那说明你还没有踏入那扇门。"
>
> — 凯蒂·维兰德（引詹姆斯·斯考特·贝尔），第六章

---

## I — 方法论骨架 (Interpretation)

激发事件是"打翻第一张多米诺骨牌、颠覆人物世界"的事件。判定它的标准是**门测试**：问"主人公能否退回从前的安稳生活？"——能，就还没踏入故事的门。

它不必是惨剧（搬家、新工作、遇到某人、养宠物都算），但必须满足**四特质**：
1. **直接影响之后的情节**（拿掉它，后续还能照常上演，就不算）；
2. **制造冲突**（变化越大，冲突越烈）；
3. **抓住读者注意力**（足够特别）；
4. **引发动作**（人物必须真正行动，带来不可逆的变化）。

位置：一般安排在**小说四分之一处或之后**，先让读者认同人物，事到临头才感到紧急。

---

## A1 — 书中的应用 (Past Application)

### 案例: 《角斗士》的激发事件
- **问题**: 一部史诗片，故事真正从哪一刻启动？
- **方法论的使用**: 皇帝马库斯·奥里利乌斯离世（在此之前皇帝提出由主人公继位等场景只是铺垫，未颠覆世界）。
- **结论**: 皇帝离世引发继位、迫害、家人被杀等一系列不可逆事件，通过四特质检验。
- **结果**: 观众先认同人物（开场战斗、与皇帝往来），激发事件才隆重上演，事态紧急感拉满。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户的开头一直平淡，读者看不下去。
2. 用户不确定"我的故事到底该从哪个事件开始"。
3. 用户设计了一个大事件，但拿不准它够不够格当"转折点"。
4. 用户想给故事找个"回不去了"的起点。

### 语言信号

- "我的开头太平淡""故事什么时候开始"
- "这个事件够不够当转折点""激发事件放哪"
- "inciting event""where does the story really start"

### 与相邻 skill 的区分（初稿）

- 与 `structure-three-act` 的区别: 本 skill 只聚焦"激发事件"这一节点，三幕结构管开头-中间-结尾全流程。
- 与 `backstory-iceberg` 的区别: 激发事件是"往前看的门"，幕后故事是"门背后的过去"。

## E — 可执行步骤 (Execution)

1. **用门测试判定候选事件**（主人公能否退回从前生活？）。
   - 完成标准: 找到那个"一旦发生就回不去"的事件。
   - 判停条件: 若所有候选都能"退回"，说明故事还没真正开始，回到 scene-map 找更强冲突。

2. **用四特质打磨激发事件**。
   - 完成标准: 四特质（影响情节/制造冲突/抓注意力/引发动作）逐条勾选通过。

3. **放到正确位置**（四分之一处或之后）。
   - 完成标准: 激发事件前有足够篇幅让读者认同人物。

4. **确保人物对激发事件做出回应**。
   - 完成标准: 人物的回应方式已定（奠定小说基调），而非毫无反应。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 小说刻意无明确激发事件（如群像、散文式、日常向）——不是所有故事都需要"一扇门"。
- 用户只写开头的环境/文笔，不涉及结构节点。

### 作者在书中警告的失败模式

- **把铺垫当激发事件**：激发事件前的重要场景（如《角斗士》皇帝提出继位）重要但不颠覆世界，不算。
- **平庸的激发事件**：满足于平凡想法，抓不住读者注意力。
- **激发事件被拿掉仍能照常演**：那它就不是真激发事件。

### 作者的盲点 / 时代局限

- "激发事件放在四分之一处"是西方三幕结构经验；网文常要求"黄金三章"内出钩子，激发事件会大幅提前，需按网文节奏调整。

### 容易混淆的邻近方法论

- 与"开篇钩子（hook）"的区分: 钩子是吸引读下去的悬念，激发事件是颠覆世界的事件，两者相关但不同。
