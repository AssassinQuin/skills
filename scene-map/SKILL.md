# 小说示意图（连点成画）

## R — 原文 (Reading)

> "你现在所知道的几个场景就相当于'连点成画'游戏里的点，你的任务就是根据点的分布想出连点的方法，并且解释这样做的原因……你可以一眼看出小说缺失的部分。"
>
> — 凯蒂·维兰德，第四章

---

## I — 方法论骨架 (Interpretation)

你脑子里零散的场景，就是"连点成画"游戏里的**点**。示意图的任务分三步：①**概述/列出**所有已知场景（不追求完整，可以写"接下来不清楚"）；②**标出问题**——在讲不通、模糊处做标记（作者用下划线/荧光笔），这些空白就是情节漏洞；③**连点成画**——挑最棘手的问题，用"如果/为什么"反复提问，把点连起来。

关键心法：此刻你没有"描写完整场景、丰富人物、完善对白"的牵挂，所以能集中精力攻克"点与点之间的空白"。这是一张**全景地图**，不是完整初稿。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《守望黎明》的场景概述 + 标出问题
- **问题**: 作者要梳理一部历史小说的情节。
- **方法论的使用**: 以"我对这本小说有什么了解？"开头，按时间顺序写下十几页概述，在"出于某个重要原因他们成了婚""他有一个敌人"等模糊处加下划线。
- **结论**: 未知领域被显性化，成为"通往探险的神秘通道"。
- **结果**: 之后写提纲时，只誊写蓝色荧光笔画出的翔实部分。

### 案例 2: 连点成画破解"谁是安兰的敌人"
- **问题**: 场景清单列完后，最棘手的问题是"谁是安兰的敌人？为什么？"。
- **方法论的使用**: 尝试多种方案——"敌人是主教？""安兰是逃跑的僧侣？""好友冤死在主教手上？"。
- **结论**: 反复提问后找到讲得通的答案（因心寒而离开教会）。
- **结果**: 填补了情节的关键空白。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户脑子里有一堆零散场景、人物经历、点子，但串不起来。
2. 用户发现自己情节有漏洞，或场景之间接不上。
3. 用户不知道从哪个场景开始写、怎么过渡。
4. 用户刚做完头脑风暴，需要把一堆点子整理成有序结构。

### 语言信号

- "我有一堆场景但连不起来""场景之间怎么过渡"
- "我的情节有漏洞""这里接不上""不知道从哪开始"
- "帮我整理一下这些片段""scene map""plot holes"

### 与相邻 skill 的区分（初稿）

- 与 `what-if-brainstorm` 的区别: 那是在"点子→故事"层面发散，本 skill 在"场景→情节"层面连点。
- 与 `reverse-outline` 的区别: 本 skill 正向连点（从已知场景出发向前推），逆向提纲从结局倒着填。

---

## E — 可执行步骤 (Execution)

1. **按时间顺序写下所有已知场景**（不管格式、不管第一章始于何处）。
   - 完成标准: 所有已知片段都落成清单，含"临时想到"的碎片。

2. **在讲不通/模糊处做标记**（下划线、批注"不清楚/太模糊"）。
   - 完成标准: 每处漏洞都被显性标记，漏洞清单可见。

3. **挑最棘手的问题，用"如果/为什么"提问连点**。
   - 完成标准: 每个标记处都尝试了 ≥2 种方案，并选出一个讲得通的。

4. **用身体/直觉筛选方案**（哪个方案让你心跳加速）。
   - 完成标准: 留下的方案不止"逻辑通"，还能打动你自己。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户一个场景都没有、纯空白（先发散，用 what-if-brainstorm）。
- 要写完整场景的描写/对白（这是初稿阶段，不是示意图）。

### 作者在书中警告的失败模式

- **把示意图当成初稿写**：追求完整场景、丰富人物，反而失去"集中攻克空白"的优势。
- **东拼西凑充数**：在讲不通处硬塞不相干情节（这也是逆向提纲要解决的问题）。

### 作者的盲点 / 时代局限

- "标出问题"依赖作者先有足够多的已知点；对完全从零开始的新手，可能"点"太少，需要先喂素材。

### 容易混淆的邻近方法论

- 与"逆向提纲"的区分: 正向连点 vs 倒着填空白，两者互补（正向卡住时换逆向）。
