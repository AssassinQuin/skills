## 核心认知（写在前面的三句话）

1. **科学定投的卖出，本质是"规则触发"，不是"预测顶部"**——没人能科学预测顶部，但你可以用规则让自己不贪不慌。
2. **再平衡天然回答了"卖多少"**——涨多了自动偏离目标比例，触发卖出超配，机械执行。
3. **分批永远优于一把梭**——无论是买还是卖。放弃最高点/最低点，换取不踏空、不套牢的概率。
