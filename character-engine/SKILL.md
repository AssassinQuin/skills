# 动机-愿望-目标链（人物引擎）

## R — 原文 (Reading)

> "人物的动机会点燃他们的愿望，愿望则会引领他们迈向目标……小说的核心是主人公的某种愿望。倘若没有愿望，主人公何以熬过一页又一页的冲突？"
>
> — 凯蒂·维兰德，第五章

---

## I — 方法论骨架 (Interpretation)

人物的行动不能凭空而来，必须可追溯到一条**三级因果链**：动机（他为什么想要）→ 点燃愿望（他渴望什么）→ 引领目标（他具体要得到什么）。愿望要足够强烈，目标要足够清晰，整本书就围绕"追逐愿望 + 途中受阻"展开。

关键洞见（卡德引文）：**人物如何定义，取决于他想做什么，而非他做了什么**。所以判断人物，先问"他想成为什么样的人/想要什么"，而不是"他干了什么"。行动与动机的**错位**（表面做好事、其实另有目的）正是塑造复杂人物的空间。

配套原则：人物必须在故事中**有所改变**，且不能浮于表面（内在价值、道德观也要变），并用**行动**而非誓言来证明改变。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《守望黎明》的动机清单
- **问题**: 作者要理清一群人物的行动逻辑。
- **方法论的使用**: 逐条列出每个人的动机与行动（"安兰觉得自己罪恶深重，想战死沙场""梅雷亚德想尽快逃离圣地"）。
- **结论**: 每个行动都有了可追溯的动机。
- **结果**: 复杂人物关系（师徒、仇敌、契约）有了内在逻辑。

### 案例 2: 郝思嘉的愿望链（《飘》）
- **问题**: 为什么《飘》后半段郝思嘉一切举动都成立？
- **方法论的使用**: 追溯她的动机"我不要再饿肚子了"→ 渴望安全感 → 追求财富与地位。
- **结论**: 强烈动机点燃愿望、愿望引领目标。
- **结果**: 读者理解并跟随她的每个选择。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户设计主人公，但不知道他"为什么"要做这些事。
2. 用户写出来的人物读者不关心、没代入感。
3. 用户想设计一个"动机与行动错位"的复杂人物。
4. 用户要检查人物在故事里的成长弧线是否成立。

### 语言信号

- "我的人物太平了""读者不关心他""人物没动机"
- "他为什么要做这件事""人物的愿望是什么""目标呢"
- "motivation""character goal""character arc"

### 与相邻 skill 的区分（初稿）

- 与 `character-interview` 的区别: 本 skill 设计"动机-愿望-目标"这条驱动力，采访负责填"外貌/性格/背景"等细节。
- 与 `conflict-engine` 的区别: 本 skill 回答"人物想要什么"，冲突引擎回答"怎么阻止他得到"。

---

## E — 可执行步骤 (Execution)

1. **写下人物每个关键行动的动机**（他为什么这么做）。
   - 完成标准: 每个主要行动都能追溯到一句"因为……"。

2. **从动机推导愿望**（他内心最深的渴望）。
   - 完成标准: 愿望足够强烈，强烈到能撑过整本书的挫折。

3. **从愿望锁定具体目标**（可执行、可追逐）。
   - 完成标准: 目标是"具体到可被阻碍"的（一个东西/一个人/一个地方）。

4. **设计人物弧线**（起点有缺陷 → 经历改变 → 用行动证明改变）。
   - 完成标准: 起点/终点有对照，且改变通过行动（非誓言）体现。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要人物设定表（外貌/爱好），不关心驱动力——用 character-interview。
- 纯网文"金手指/升级"驱动、人物无内在弧线的类型，强行套"愿望-成长"会适得其反。

### 作者在书中警告的失败模式

- **动机无趣**：仅仅让人物做有趣的事不够，行动背后的动机也必须有趣（读者爱看人物"为什么"做）。
- **人物不改变**：人物必须有所改变，且内在价值、道德观念也要变，不能浮于表面。
- **只用誓言证明改变**：人物发誓"要做个好人"难以令读者信服，必须用行动证明。

### 作者的盲点 / 时代局限

- "人物必须有强烈愿望 + 成长弧线"是西方传统叙事硬指标；网文主角常以"能力/资源成长"代替"道德弧线"，本框架需相应调整（愿望可以是"变强/复仇/争第一"）。

### 容易混淆的邻近方法论

- 与"人设表"的区分: 人设表是静态属性，动机-愿望-目标是动态驱动力。
