## 核心结论（一句话）

**银发经济是 30-50 年的文明级机会。当前 A 股+港股医疗估值处于历史低位（PE 12.84% 分位），是"逆向价值投资"的良机——但前提是用户愿意放宽 15% 回撤约束到 -20%。**

## 用户画像（延续墨脱研究）

- 保守型（最大回撤 < 15%）
- 仅 ETF + 利率债/信用债
- 长期持有 5 年+
- 卫星仓位 10-20%
- 3 年内不动用
- 子赛道：医疗保健 + 养老服务 + 银发综合 + 老年消费（全选）
- 区域：全球（A 股 + 港股 + 美股）
