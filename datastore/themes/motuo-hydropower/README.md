## 核心结论（一句话）

**墨脱水电站是确定性极高的国家级世纪工程，但普通人的"15% 回撤 + 10-20% 卫星 + ETF/债券"组合不存在满足解——所有墨脱主题股票 ETF 历史最大回撤 -17% 到 -30%，全部突破 15% 硬约束。**

## 用户画像

- 保守型（最大回撤 < 15%）
- 仅 ETF + 利率债/信用债
- 长期 5 年+
- 卫星仓位 10-20%

→ 与主题敞口形成不可能三角（详见主报告 §4）
