- id: f01
  title: 左右脑四步循环（构思-提纲-创作-修改）
  type: framework
  source_chapter: 第一章 我们应该写提纲吗?
  source_quote: |
    "加上提纲，小说的创作过程可分为四步：构思、写提纲、创作、修改。构思主要是一项右脑活动；写提纲时，左脑首次登场；创作时，右脑高速运转；修改意味着左脑理性思维的又一次回归。"
  summary: |
    把创作拆成左右脑交替主导的四步：构思（右脑想象）→提纲（左脑逻辑检验）→创作（右脑放飞）→修改（左脑善后）。
    关键是"把单调的逻辑工作前置到提纲阶段"，从而在写初稿时解放右脑、安心探索细节。
    可迁移到任何创作型任务：先把需要理性检验的部分做完，再进入自由输出。
  tags: [process, workflow, brain-hemisphere, creation]

- id: f02
  title: 「如果」问句（What-If 头脑风暴）
  type: framework
  source_chapter: 第三章 雕琢好小说的前提
  source_quote: |
    "多数前提又源于如果：如果一个小男孩头脑发育过快，身体跟不上脑袋瓜的发展会怎样？……把'如果'问句清楚地写出来，这些问句能够放飞你的想象力，你可以看到之前没有看到的可能。"
  summary: |
    面对一个题材，故意疯狂地列出"如果 X 会怎样"的问句，不设限、不自我审查。
    多数"如果"站不住脚也没关系，它们的价值在于打开想象力的阀门、从全新角度切入。
    即使某个想法行得通，也要继续追问"如果发生的其实是另一件事会怎样"。
  tags: [ideation, brainstorming, creativity, what-if]

- id: f03
  title: 前提句（一句话锁定小说）
  type: framework
  source_chapter: 第三章 雕琢好小说的前提
  source_quote: |
    "你的任务是用一句话涵盖小说的人物、背景和主要冲突……如果你能将小说的要素成功地浓缩为一句话，不论是写提纲，还是写初稿，你都不必担心找不到北了。"
  summary: |
    把"如果"问句的成果浓缩为一句前提句，锁定主人公、主要冲突与大致情节。
    前提句是迷你版提纲：用来检验想法是否可行、提炼精髓、作为北极星引导下一步提问，也能当推销材料。
    核心动作是"压缩"——无法压缩成一句话，说明想法还没想清楚。
  tags: [compression, definition, premise, north-star]

- id: f04
  title: 挖掘前提潜能（对前提继续发问）
  type: framework
  source_chapter: 第三章 雕琢好小说的前提
  source_quote: |
    "好好审视一番你的前提，确认你是否发掘了它的一切潜能。不要满足于显而易见的答案……卡德很可能问过，如果主人公可以通过时光之旅穿越到九世纪，那让他和俄罗斯公主一起穿越到今天的美国，又有何不可？"
  summary: |
    得到可行前提后，不要急着满足，继续对前提追问"还能走多远"，用"如果……那……又有何不可"强迫自己跳出定式思维。
    奥森·卡德把睡美人童话拓展成两个世界的穿越，就是靠充分挖掘前提的潜力。
    适用于任何创意：检验一个灵感是否被榨干，而非停留在第一个"够用"的答案。
  tags: [ideation, premise-expansion, second-order-thinking]

- id: f05
  title: 梦想风暴（让潜意识接管）
  type: framework
  source_chapter: 第三章 雕琢好小说的前提
  source_quote: |
    "它们之所以有效，是因为它们可以帮助我们越过大脑吹毛求疵的一侧，直接进入深层的'梦想领域'……切忌自我审查。创造力是一朵既羸弱又多愁善感的花儿。"
  summary: |
    头脑风暴时刻意让理性一侧休息：给幻想时间、切忌自我审查、让左脑安静、抓住感觉（视觉/听觉/嗅觉）、相信直觉。
    逻辑思维负责事后在混沌中理出头绪，但震撼力源于潜意识——两者分工，先右后左。
    适用于一切需要原创产出的场景：先无评判地生成，再理性筛选。
  tags: [ideation, subconscious, creativity, brainstorming]

- id: f06
  title: 读者期待法（列期待、设转折）
  type: framework
  source_chapter: 第三章 雕琢好小说的前提
  source_quote: |
    "在一连串'如果'下面，我又提出了新的问题，'读者会期待什么？'我尽可能多地列出读者的阅读期待，这样，我就可以在合适的地方设置意想不到的转折。"
  summary: |
    主动列出目标读者会期待什么（期待主角相爱、期待坏人失败、期待主角本性善良），然后逐一决定满足还是颠覆。
    在读者预期之处埋下张力；再追问"什么会让读者大吃一惊"，据此设计反转。
    可迁移为内容创作的反向设计：先穷举受众预期，再决定在哪些点兑现、哪些点打破。
  tags: [audience, expectation, twist, reverse-design]

- id: f07
  title: 完美评述（动笔前写理想书评）
  type: framework
  source_chapter: 第二章 写提纲之前
  source_quote: |
    "你只需在动笔前写一份'完美'的小说评述，就可以缩小构想与成书的距离……闭上眼睛，在情感上从自己的作品中抽离，然后把自己想象成这位评论家。"
  summary: |
    动笔前，想象一位完全读懂你脑中之书的专业评论家，写下他如何评价这本书。
    三原则：具体（给理由）、全面（情节/人物/对话/主题/高潮都评）、满足（尽情称赞）。
    写完即得到清晰目标，后续创作有方向可去——用"理想终态"反推起点。
  tags: [goal-setting, vision, reverse-thinking, review]

- id: f08
  title: 小说示意图（连点成画）
  type: framework
  source_chapter: 第四章 小说示意图（Ⅰ）：连点成画
  source_quote: |
    "你现在所知道的几个场景就相当于'连点成画'游戏里的点，你的任务就是根据点的分布想出连点的方法，并且解释这样做的原因……你可以一眼看出小说缺失的部分。"
  summary: |
    先把已知场景以清单形式列出来（不追求完整、可以写"不清楚/太模糊"），在讲不通处做标记，再通过大量提问把点连起来、填补空白。
    本质是把"知道的点"与"不知道的空白"可视化，让漏洞自己显现。
    适用于任何规划类任务：先盘点已知，标记未知，再逐点攻破。
  tags: [planning, scene-map, gap-analysis, visual-thinking]

- id: f09
  title: 提问取代陈述（句号变问号）
  type: framework
  source_chapter: 第四章 小说示意图（Ⅰ）：连点成画
  source_quote: |
    "要善于将陈述句改写为问句，比如'公主被困在高塔中'可改为'我怎样才能将公主从高塔中救出呢？'一个简单的问号，可以释放出令人惊叹的创造力。"
  summary: |
    思路中断时，把陈述句改写成问句——句号堵死灵感，问号像转门吸引人继续探索。
    只要保持强烈好奇心、在情节捋顺后仍再往前问一步（"如果发生其他事件会怎样？结果会改变吗？"），就能不断打开新可能。
    可迁移为通用问题解决法：卡住时把"现状陈述"翻转为"如何达成"的开放问题。
  tags: [questioning, problem-solving, creativity, unblocking]

- id: f10
  title: 身体反应筛选法（直觉做判官）
  type: framework
  source_chapter: 第四章 小说示意图（Ⅰ）：连点成画
  source_quote: |
    "如果一个想法足以令我肺部缺氧、喘不过气，那我肯定是得到了缪斯女神的青睐……我们的'大脑委员会'可能会带我们走上歧途，但我们的直觉很少出错。"
  summary: |
    判断一个想法是否有价值，不只看逻辑，更用身体与情感反应来检验：好点子让你心跳加速、呼吸急促、像高空跳水。
    先让小说打动自己，才能打动读者；读者共鸣极主观，但"自己无感必不感人"是硬底线。
    可迁移为创意筛选器：在理性评估前，先记录直觉/身体层面的真实反应。
  tags: [intuition, decision, emotional-response, filtering]

- id: f11
  title: 动机-愿望-目标链
  type: framework
  source_chapter: 第五章 小说示意图（Ⅱ）：小说的核心元素
  source_quote: |
    "人物的动机会点燃他们的愿望，愿望则会引领他们迈向目标……小说的核心是主人公的某种愿望。倘若没有愿望，主人公何以熬过一页又一页的冲突？"
  summary: |
    三层因果链条：动机点燃愿望，愿望引领目标。行动的驱动必须可追溯——先问人物"想做什么"，再让目标派生障碍、产生冲突。
    愿望要足够强烈，目标要足够清晰，整本书围绕追逐与受阻展开。
    可迁移为一切人物/主角设计的引擎：没有愿望就没有张力，没有动机的行动读者不会买账。
  tags: [character, motivation, goal-chain, causality]

- id: f12
  title: 制造冲突 = 人物与目标之间加障碍
  type: framework
  source_chapter: 第五章 小说示意图（Ⅱ）：小说的核心元素
  source_quote: |
    "当你知道了人物的动机、愿望和目标时，制造冲突不过是在人物与目标之间添加障碍罢了……对人物而言，他所能遭遇的最糟糕的事是什么？设法写出十种可能。"
  summary: |
    知道了动机愿望目标后，冲突的制造就是"在人物与目标之间加障碍"。
    可执行步骤：写十种"人物能遭遇的最糟糕的事"（不行再写十种）→ 检查每个场景人物的挫折 → 一张一弛调节强度，防拖沓、防无趣。
    反派定义放宽为"任何阻碍目标实现的人"。可迁移为通用故事引擎：冲突=目标×障碍。
  tags: [conflict, obstacle-design, escalation, story-engine]

- id: f13
  title: 延迟满足术（靠近目标又推回）
  type: framework
  source_chapter: 第五章 小说示意图（Ⅱ）：小说的核心元素
  source_quote: |
    "艾略特在《米德尔马契》中，将延迟满足的艺术发挥到了极致。她为人物赋予强烈动机、愿望、目标的同时，又冷峻地拒绝了一切实现的可能……一次次让人物靠近目标，却又一次次将他们推回原处。"
  summary: |
    让目标始终可见、始终渴望，但一次次拒绝实现——每次接近都被推回，读者被好奇心驱动读完长篇。
    这是"如何让人物不轻易得手"的节奏框架：愿望越强烈，阻碍越冷峻，张力越持久。
    可迁移为长线叙事与钩子设计的核心：兑现之前先反复拉扯。
  tags: [tension, suspense, pacing, delayed-gratification]

- id: f14
  title: 主题发现五问（用人物轨迹显化主题）
  type: framework
  source_chapter: 第五章 小说示意图（Ⅱ）：小说的核心元素
  source_quote: |
    "你要向自己提出以下问题：主人公的内在冲突是什么？随着小说的发展，主人公的哪些观念发生了变化？开头与结尾，主人公如何证明自己前后不同的观念？你能否通过象征的手法强化主题？你应如何通过潜文本印证主题？"
  summary: |
    不直接贴标语，而是用五个问题把主题从人物轨迹里"挖"出来：内在冲突→观念变化→前后证明→象征强化→潜文本印证。
    主题通过人物的行动和变化体现，最好的主题"毫不费力甚至不留痕迹地从人物行动中体现"；小说家的任务是提出问题而非解答问题。
    可迁移为任何"想传达观念"的创作：观念必须落在人物弧线上，而非喊口号。
  tags: [theme, character-arc, subtext, discovery]

- id: f15
  title: 激发事件判定与定位（门测试）
  type: framework
  source_chapter: 第六章 人物速写（Ⅰ）：探索幕后故事
  source_quote: |
    "关键是要问自己，主人公能否从情节中顺利脱身，继续过他从前的安稳生活？如果答案是肯定的，那说明你还没有踏入那扇门。"
  summary: |
    判定一个事件是否为"激发事件"，用门测试：主人公能否退回从前的安稳生活？能→还没触发故事。
    四个硬特质：直接影响之后情节、制造冲突、抓住读者注意力、引发动作（不可逆）；一般安排在小说四分之一处或之后，给读者足够时间认同人物。
    可迁移为故事开篇的验证框架：先确认"回不去了"，再谈故事真正开始。
  tags: [structure, inciting-event, verification, turning-point]

- id: f16
  title: 幕后故事探索流程（以激发事件为跳板）
  type: framework
  source_chapter: 第六章 人物速写（Ⅰ）：探索幕后故事
  source_quote: |
    "你可以尝试越过起点，直接将目光聚焦于幕后故事的终点：激发事件……尽早提供线索以暗示幕后故事的存在，但请等到最后一刻再揭示它。简洁有力地勾勒幕后故事，篇幅越短越好。"
  summary: |
    探索人物过去时不从出生顺写，而从激发事件倒推：问"激发事件的种子埋在他过往哪些经历中、他为何如此应对、哪些遗留问题让它更棘手"。
    操作顺序：总体概述→其他重要人物→教育/职业/旅途→大事件（点金石）。
    使用铁律：冰山式运用——早暗示、最后一刻揭示、篇幅越短越好。
  tags: [backstory, character-depth, reverse-thinking, iceberg]

- id: f17
  title: 人物采访（分类问题清单）
  type: framework
  source_chapter: 第七章 人物速写（Ⅱ）：人物采访
  source_quote: |
    "你可以采取人物采访的形式以加深对人物的了解。我最初的采访仅有二十多个问题……如今，我有一百多个具体而刁钻的问题，我通过它们同人物交谈，寻找灵感。"
  summary: |
    用结构化问题清单（基本信息/人生观/外貌/性格/兴趣爱好/希望与梦想等类别，含"最在意的、秘密、核心需求"）逐项采访人物，穷尽人物细节。
    主要精力放在主人公与反派上；创作时反复回查答案核对一致性。
    可迁移为任何角色/对象的系统化了解：先按维度提问，再让细节自然长出来。
  tags: [character, interview, checklist, discovery]

- id: f18
  title: 自由采访（与人物对话逼出真相）
  type: framework
  source_chapter: 第七章 人物速写（Ⅱ）：人物采访
  source_quote: |
    "你不需要问前面的常规性问题，你只需和他在纸上展开对话即可。你抛出许多问题……不知不觉中，人物向你坦白，你听到许多意想不到的回答。"
  summary: |
    常规采访失效时，直接以对白形式质问人物："你到底在想什么？你为什么总是逃避我？"
    连续追问、反驳人物的借口，直到某个回答让你"啊"的一声——那就是人物的真实动机（如"如果她们不需要我，她们就不爱我"）。
    可迁移为深度调研/用户访谈技巧：用对抗式追问穿透表层合理化。
  tags: [character, interview, dialogue, insight]

- id: f19
  title: 背景四问（检验背景价值）
  type: framework
  source_chapter: 第八章 发现小说背景
  source_quote: |
    "写提纲时，为了避免在背景上出问题，为了尽可能发挥出其价值，你可以向自己提以下问题：背景是否为小说的有机组成部分？人物如何看待他所生活的背景？背景能否牵动读者的情绪？你是否过度使用背景了？"
  summary: |
    用四个问题验证背景是否物尽其用：是否有机融入情节（而非幕布）、人物如何感知它（借背景揭示身份）、能否调动读者情绪、是否过度堆砌。
    配套优化手段：慎重选主要背景、写透一个而非走马观花多个、次要背景"合众为一"、为反复出现的背景铺设线索。
    可迁移为一切场景/世界观设计的价值审查：场景不为人物与情绪服务就该砍。
  tags: [setting, worldbuilding, validation, consolidation]

- id: f20
  title: 世界建构问题集（按维度自问）
  type: framework
  source_chapter: 第八章 发现小说背景
  source_quote: |
    "我总结了世界建构的相关主题及问题：这个世界的自然风光、社会形态、自然法则、居住的人、历史是怎样的？作答时，尽管放开自己，就像做人物采访一样。"
  summary: |
    构建虚构世界时按五大维度自问并作答：自然风光（植物/气候/动物）、社会形态（衣着/观念/语言/政府/科技/战争）、自然法则（与现实的差异/魔法及其限制）、居民（种族/风俗/民族关系）、历史（可追溯多久/哪些时期影响社会）。
    作答时像人物采访一样不设限、先记下再说，即便掌握细节也坚持答完以暴露漏洞与不协调。
    可迁移为任何虚构设定的系统性头脑风暴框架。
  tags: [worldbuilding, systematic-questioning, fiction, detail]

- id: f21
  title: 视角选择三问（谁的故事谁来讲）
  type: framework
  source_chapter: 第九章 扩展版提纲：创作一部小说
  source_quote: |
    "为了帮助你选择合适的视角，我特地列出以下四点注意事项：选取适量的视角……选择最恰当的视角……选择最能打动人的视角……玩转叙述声音和时态。"
  summary: |
    选择叙述视角的三个递进问题：①适量的视角——新视角是否非加不可？能用现有人物就别加；②最恰当的视角——这一场景谁受冲击最大、谁最能提供新东西；③最能打动人的视角——比较多个候选人，别满足于显而易见的选择，让语调契合人物。
    视角决定小说成败，且可以大胆尝试新时态以精进技巧。
    可迁移为所有"以谁为叙述主体"的决策框架。

- id: f24
  title: 多米诺效应（场景价值验证）
  type: framework
  source_chapter: 第九章 扩展版提纲：创作一部小说
  source_quote: |
    "如果一个场景无法影响之后的场景，如果它的存在对小说毫无意义，你可能要删去它。如果你能把它调整到位，那自然更好……每个场景，不论看起来多么无关痛痒，都有其存在理由。"
  summary: |
    把小说看作多米诺方阵：每个场景都是骨牌，必须"缺一不可"——删除不影响后续的场景，或把它调整到位。
    反直觉的判据：看似填充的场景可能是关键骨牌（修女一幕是主人公的转折点），所以删除前先检验它对后续的影响链。
    可迁移为任何流程/章节的精简判据：砍掉对结果无贡献的环节，但先验证"隐性关键环节"。

- id: f25
  title: 逆向提纲（从已知终点倒着写）
  type: framework
  source_chapter: 第九章 扩展版提纲：创作一部小说
  source_quote: |
    "此时，从最后一个场景开始倒着写，往往更简单、更高效……当你从已知信息出发，倒着走时，你会发现你的任务不过是一道简单的填空题。"
  summary: |
    当不知道 A 到 B 怎么连时，从更确定的终点 B 倒着推：持续问"他是如何受伤的、在哪里、为什么、为何没死、怎么逃的"，把未知变成一道道填空题。
    先定自己更了解的已知点，从它出发向两边补全，避免东拼西凑的生硬情节。
    可迁移为通用规划技巧：正向卡住时，从确定的结果反向设计路径。
  tags: [reverse-thinking, planning, outline, fill-in-blanks]

- id: f27
  title: 两级提纲法（扩展版 → 精简版）
  type: framework
  source_chapter: 第十章 精简版提纲：画好你的路线图
  source_quote: |
    "写完扩展版提纲后，你要提炼相关信息，整理出精简版提纲……避免漫无目的地游走……衡量每个场景的价值，完善薄弱环节，剔除可有可无的部分。"
  summary: |
    先写详尽的扩展版提纲（试验田，探索各种可能、标出问题），再提炼出可读的精简版路线图（只留结论、纠正错误、一眼看清重要站点）。
    第二步同时是一次过滤：删去重复/不相干/"如何得出结论"的过程文字，衡量每场景价值、砍掉多余脂肪（尤其是场景过渡处的赘笔，可用场景切换代替过程描写）。
    可迁移为"先粗后精、两遍成稿"的信息处理范式。

- id: f28
  title: 场景五问（莱文法）
  type: framework
  source_chapter: 作家访谈：贝琪·莱文
  source_quote: |
    "每个场景都有不少问题亟需解决：主人公的目标、路途上的障碍（包括其来源）、她应对障碍的对策、她是否克服了障碍（结果经常是否定的）、如果她失败了后果是什么等。"
  summary: |
    设计每个场景前，用五个问题定位它在故事中的功能：目标是什么、障碍是什么（及来源）、对策是什么、是否克服（通常是否定的）、失败后果是什么。
    答案并不要求抠细，但能让场景有明确功能、并为章节末尾留悬念铺路。
    可迁移为一切场景/任务的决策前置检查：先问清目标与代价再动手。
  tags: [scene, decision, structure, stakes]

- id: f30
  title: 索引卡洗牌排序法
  type: framework
  source_chapter: 作家访谈：萝丝·莫里斯
  source_quote: |
    "我会先将想法逐一写到索引卡上，之后我会通过洗牌的方式找到小说的最佳排序。换言之，在了解小说整体布局和各要素关系之前，事件在何处发生、真相在何时揭露，都不在我的考虑范围之内。"
  summary: |
    把每个想法/事件写在独立卡片上，先不关心顺序，把整体都摊开后再通过"洗牌"寻找最佳排序。
    关键心法：先重内容与关系，后定时间与位置——在理解整体之前，拒绝被线序绑架。
    可迁移为模块化内容规划：把要素解耦成可自由重排的单元，再求最优序列。

- id: f31
  title: 四步逐层浓缩法（赫德伦德）
  type: framework
  source_chapter: 作家访谈：朱迪·赫德伦德
  source_quote: |
    "第一步，我会就情节展开头脑风暴……第二步，我会就主要人物展开头脑风暴……第三步，我会写出简要的情节提纲……第四步，准备就绪后，我会为每个章节写一段话。"
  summary: |
    从零到成稿的递进式规划：①情节头脑风暴（记下一切想法）→②人物头脑风暴（人物成型后誊到表格）→③从成果中挑出重要事件按序排列并设法衔接→④为每章写一段话，看出开头、中间、结尾。
    每一层都站在上一层成果上做减法与衔接，逐步收窄。
    可迁移为复杂创作/项目的"发散→收敛"分步法。

- id: f32
  title: 卡片台阶法（卡芙曼）
  type: framework
  source_chapter: 作家访谈：卡洛琳卡·卡芙曼
  source_quote: |
    "我会将小说的主要情节点写在索引卡上，卡片于我而言就是台阶……如果我有一个成熟的想法，而它又介于两张卡片之间，我大可以插入一张新卡片。有必要的话，我也可以去掉一些卡片，或将卡片重新排序。"
  summary: |
    把主要情节点写成独立卡片当作"台阶"：坐下后知道在何处落脚，减少面对空白页的迷茫；随时可在两卡之间插入新卡、删卡或重排。
    卡片足够灵活，不会像传统提纲那样把人锁进牢笼，还允许创作过程中人物意料之外的发展改变全局。
    可迁移为灵活的任务/内容管理：用可增删重排的原子单元代替刚性大纲。
  tags: [modular, flexibility, atomic-units, planning]
