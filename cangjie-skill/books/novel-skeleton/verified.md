# 三重验证结果 — 《小说的骨架：好提纲成就好故事》

> 阶段 1.5 产出。候选池 101 条原子单元（框架 32 + 原则 69）合并去重后 → **15 个通过验证的方法论单元**，将构造成独立 skill。
> 每个单元列出：合并的候选 id、V1/V2/V3 判定与理由。

## 通过验证的 15 个单元（→ 阶段 2 构造成 skill）

### 1. outline-mindset — 提纲心态（指南非铁律 / 个性化 / 价值）
- 合并候选: p01, p02, p03, p04, p05, p06, p07, p08, p67, p68, p69
- V1 跨域: ✅ 全书反复出现——第一章（海盗准则"指南非铁律"）+ 第十一章（"指南不是铁律"原句复现）+ 10 位作家访谈反复强调"过于死板会扼杀创造力"（赫德伦德/卡芙曼/海斯）
- V2 预测力: ✅ 新问题"写提纲会不会束缚我的创造力？"→ 用"探索乐趣前移 + 作家是缔造者非奴隶"回答，结论"提纲反而带来自由，因为它在初稿前替你做完逻辑工作"
- V3 独特性: ✅ 反直觉——常识是"提纲=束缚"，作者论证"提纲=自由来源"；且"先写提纲胜过返工"用 8 个月 50 页烂稿的成本账反直觉地证明"写提纲是因为懒"
- → 这是整个流水线的元框架，是给"不知道提纲是什么"的初学者的入口

### 2. what-if-brainstorm — "如果"问句头脑风暴
- 合并候选: f02, f04, f05, f06, p11, p13, p14, p16
- V1 跨域: ✅ 第三章（守望黎明"如果"问句清单 13 条）+ 第三章（读者期待法/挖掘前提潜能）+ 作家访谈（克雷格"以如果问句切入头脑风暴"）
- V2 预测力: ✅ 新问题"我只有一个模糊点子，怎么把它展开成故事？"→ 疯狂列"如果 X 会怎样"问句、不自我审查、再列"读者期待什么"设反转
- V3 独特性: ✅ 反直觉——"故意疯狂列如果、多数站不住脚也没关系"违背"只写有用的"的常识；且"读者期待法"（先穷举读者预期再决定满足/颠覆）是独特的反向设计
- 含子技术: 挖掘前提潜能（f04/p13）、读者期待法（f06）、不自我审查/梦想风暴（f05/p14/p16）

### 3. premise-sentence — 前提句（一句话锁定小说）
- 合并候选: f03, p12, p15
- V1 跨域: ✅ 第三章（前提句定义 + 梦境者前提句实例）+ 第三章（前提句 7 项好处：检验可行性/明确人物冲突情节/提炼精髓/引导下个问题/回应好奇/推销准备）+ 作家访谈（克雷格"概要类似封底"）
- V2 预测力: ✅ 新问题"我怎么知道一个点子能不能撑起整本书？"→ 压缩成一句话前提句，压不出来=想法没想清
- V3 独特性: ✅ "前提句"是特鲁比/维兰德的特定术语，比"写个故事简介"精确得多——它要求同时锁定主人公(姓名职业个性)+冲突+情节，且是"迷你版提纲"

### 4. scene-map — 小说示意图（连点成画）
- 合并候选: f08, f09, f10, p17, p18, p19, p20, p21, p22
- V1 跨域: ✅ 第四章（守望黎明场景概述/梦境者场景列表）+ 第四章（标出问题/荧光笔系统）+ 第四章（连点成画破解"谁是安兰的敌人"）+ 作家访谈（萝丝·莫里斯"连接点填补空白"）
- V2 预测力: ✅ 新问题"我脑子里一堆零散场景但连不起来，怎么办？"→ 先盘点已知(列场景)、标出未知(下划线)、再用提问连点
- V3 独特性: ✅ "先盘点已知+标出未知+连点"是可执行的具体流程，且"标出问题/下划线"（把模糊处显性化）是反直觉的具体操作
- 含子技术: 提问取代陈述（f09/p21/p22）、身体反应筛选（f10/p20）、自由写作（p19）

### 5. character-engine — 动机-愿望-目标链
- 合并候选: f11, p23, p25, p26
- V1 跨域: ✅ 第五章（动机清单 + 郝思嘉"我不要饿肚子"+ 米德尔马契/罪与罚/爱玛多个独立例子）+ 第五章（人物必须改变 + 用行动证明转变）+ 卡德引文"人物如何定义取决于他想做什么"
- V2 预测力: ✅ 新问题"我的人物为什么没张力？"→ 检查动机-愿望-目标链是否可追溯、愿望是否足够强烈
- V3 独特性: ✅ "动机点燃愿望、愿望引领目标"三级因果链 + "人物由想做什么定义而非做了什么"（卡德引文）是独特的理论化表述，非"人物要有目标"的常识

### 6. conflict-engine — 制造冲突
- 合并候选: f12, f13, p24, p27, p28, p29, p30, p31, p32
- V1 跨域: ✅ 第五章（冲突核心 + 最糟十事 + 截止日期 + 一张一弛 + 反派定义 + 内外冲突）+ 第五章（米德尔马契延迟满足 + 纳瓦隆大炮截止日期 + 2003彼得潘内外冲突碰撞）多个独立案例
- V2 预测力: ✅ 新问题"我的场景平淡，怎么加冲突？"→ 在人物与目标之间加障碍；用"最糟十事"生成器、截止日期、反派(任何阻碍目标的人)、内外双冲突四张牌
- V3 独特性: ✅ "冲突=目标×障碍"的简洁公式 + "反派=任何阻碍目标实现的人(哪怕只是点一杯拿铁)"的反直觉定义 + "最糟十事"生成器，均非"要有冲突"的常识
- 含子技术: 最糟十事（p29）、截止日期（p30）、一张一弛（p31）、反派定义（p32）、内在/外在冲突（p27/p28）、延迟满足（f13）

### 7. theme-discovery — 主题发现与强化
- 合并候选: f14, p33, p34, p35
- V1 跨域: ✅ 第五章（主题发现五问 + 梦境者主题导向实例）+ 第五章（吉姆爷"背叛的回响"主题案例）+ 第五章（象征强化：爱国者小兵玩具 + 第五号屠宰场意象重复）多个独立案例
- V2 预测力: ✅ 新问题"我的小说想传达一个观念但怕说教，怎么办？"→ 用人物轨迹显化主题(五问)，象征留痕，潜文本印证，而不是喊口号
- V3 独特性: ✅ "小说家的任务不是解答问题而是提出问题" + "主题通过人物轨迹不留痕迹地体现" + 五问挖掘法，是理论化的方法论而非"要有主题"的常识

### 8. inciting-event — 激发事件
- 合并候选: f15, p36, p37, p38
- V1 跨域: ✅ 第六章（激发事件定义 + 门测试 + 位置四分之一处 + 四特质）+ 第六章（角斗士案例贯穿全节）+ 作家访谈/贝尔引文"能否脱身继续从前安稳生活"
- V2 预测力: ✅ 新问题"我的开头一直平淡，问题出在哪？"→ 用门测试判定"主人公能否退回从前生活"检验激发事件是否真触发
- V3 独特性: ✅ "门测试"（能否退回安稳生活=是否踏入那扇门）是独特的判定框架，且"激发事件不取决于大小而取决于四特质"（搬家也算，只要能不可逆）反直觉

### 9. backstory-iceberg — 幕后故事冰山
- 合并候选: f16, p39, p40, p41, p42
- V1 跨域: ✅ 第六章（海明威冰山比喻 + 从激发事件倒推 + 探索流程四步）+ 第六章（安兰概述被推翻 + 修道院点金石 + 克里斯车祸点金石）+ 大仲马/正午两个独立使用案例
- V2 预测力: ✅ 新问题"我怎么让人物有深度？"→ 挖水下的八分之七(幕后故事)，找"点金石"大事件而非流水账
- V3 独特性: ✅ "冰山八分之七"是海明威的经典隐喻被转用于幕后故事 + "从激发事件倒推而非从出生顺写"是反直觉的探索策略 + "早暗示晚揭示/越短越好"的使用铁律

### 10. character-interview — 人物采访
- 合并候选: f17, f18, p43, p44, p45
- V1 跨域: ✅ 第七章（100+问题分类清单）+ 第七章（自由采访对话实例"如果她们不需要我，她们就不爱我了"）+ 第七章（九型人格用于确认致命弱点）
- V2 预测力: ✅ 新问题"我的人物平面、写着写着忘设定，怎么办？"→ 用结构化问题清单穷尽人物细节并回查一致性
- V3 独特性: ✅ "自由采访"（直接以对白质问人物、逼出潜意识动机）是独特技法，非"人物要有设定"的常识；"九型人格仅用于确认而非生成"的边界也独特

### 11. setting-worldbuild — 背景四问与世界建构
- 合并候选: f19, f20, p46, p47, p48, p49, p50
- V1 跨域: ✅ 第八章（背景四问 + 山德森《最后帝国》世界建构范例）+ 第八章（太阳帝国背景正反例 + 合众为一 + 铺线索）+ 梦境者世界建构实例
- V2 预测力: ✅ 新问题"我的世界观设定很空泛，怎么充实？"→ 按五维度(自然/社会/法则/居民/历史)逐项自问作答
- V3 独特性: ✅ "背景是否为有机组成部分/人物如何感知/能否牵动情绪/是否过度"四问是独特的价值审查框架 + "合众为一"（合并次要背景）反直觉（少即是多）

### 12. pov-selection — 视角选择三问
- 合并候选: f21, p54, p55
- V1 跨域: ✅ 第九章（视角选择三点：适量/恰当/打动人心）+ 第九章（梦境者视角调整实例 + 二战小说选错视角烂尾实例）
- V2 预测力: ✅ 新问题"我这个场景写出来没张力，是文笔问题吗？"→ 先检查是否选错了视角(谁受冲击最大)
- V3 独特性: ✅ "选对事件触动最大的人物的视角"是反直觉的（不是默认主人公视角）+ "视角宁少勿多"与常识"多视角更丰富"相反

### 13. structure-three-act — 开头-中间-结尾结构
- 合并候选: f22, p56, p57, p58, p52, p53
- V1 跨域: ✅ 第九章（开头/中间/结尾清单）+ 第九章（三大基本元素幽默/动作/关系 + 首尾呼应四部电影）
- V2 预测力: ✅ 新问题"我的故事中间拖沓，怎么办？"→ 按三幕检查点核查（中间：目标渐远/设新目标/被动转对抗）
- V3 独特性: ✅ "写你的完美小说"(非完美小说) + 三大元素(幽默/动作/关系) + 首尾呼应，是结构化的清单而非"故事要有头有尾"的常识

### 14. reverse-outline — 逆向提纲
- 合并候选: f25, p61
- V1 跨域: ✅ 第九章（逆向提纲专节：布鲁斯受伤倒写回晚宴的完整实例）+ 第六章（"从激发事件倒推幕后故事"同构的倒推策略）
- V2 预测力: ✅ 新问题"我知道结局但不知道中间怎么连，卡住了，怎么办？"→ 从已知终点倒着问"如何发生/在哪/为什么/为何没死/怎么逃"，把未知变成填空题
- V3 独特性: ✅ 这是全书最独特的可迁移技巧——"倒着写"违背"按时间顺序写"的直觉，且作者用"填空题"的隐喻把复杂规划降维成可操作步骤

### 15. condense-outline — 两级提纲法（扩展版→精简版）
- 合并候选: f27, p51, p62, p65, p66, p60, p63, p64, f24
- V1 跨域: ✅ 第十章（精简版提纲四理由 + 守望黎明/梦境者精简版实例）+ 第十章（多米诺删减 + 章节结尾 11 式 + 控制节奏 + 砍脂肪）
- V2 预测力: ✅ 新问题"我提纲写了一大堆，但写初稿时根本不想看，怎么办？"→ 提炼成可一眼看清的精简版路线图，删去过程文字
- V3 独特性: ✅ "先详后精、两遍成稿"（扩展版=试验田，精简版=路线图）是独特的两遍范式 + "多米诺效应"删减判据（删掉不影响后续的场景）+ "章节结尾 11 式"（每个结尾配一个隐含问题）是具体可执行的清单
- 含子技术: 多米诺效应（f24/p60）、章节结尾 11 式（f26/p63/p64）、砍脂肪/场景切换（p66）、控制节奏（p65）

## 数量说明
- 候选池 101 条原子单元 → 合并为 15 个方法论单元，通过率 ≈ 15%（按原子单元计）。低于经验值 30-50%，原因是本书方法高度线性（每章一个阶段），同阶段内大量原子候选（如第五章的"最糟十事/截止日期/一张一弛/反派定义"都是"制造冲突"的子技术），合并后自然收敛。
- 合并后 15 个单元，正好覆盖全书 11 章的完整流水线（第一章→outline-mindset，第三章→what-if+premise，第四章→scene-map，第五章→character+conflict+theme，第六章→inciting-event+backstory，第七章→interview，第八章→setting，第九章→pov+structure+reverse，第十章→condense）。
