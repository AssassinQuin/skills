## 这本书在讲什么

凯蒂·维兰德要回答一个问题：**怎么写出一份既不影响创造力、又能真正指导初稿、避免写完十万字后返工的小说提纲？**

她的答案是反直觉的——**提纲不是束缚创造力的牢笼，而是让你动笔前看清全局的航海图**。她用自己的亲身经历做证据：《守望黎明》写了提纲，一举成为她当时最优秀的小说；下一部《梦境者》她绕回老路不写提纲，结果 8 个月只写了 50 页烂稿，返工又花近一年。她的结论是："我写提纲主要是因为我懒，我痛恨改写。"

这本书最宝贵的地方，是它把"写提纲"拆成了一条**可操作的流水线**：从一句前提句开始，逐步搭出人物、冲突、主题、背景，最后得到一份能直接指导写作的精简版路线图。下面按这条流水线展开，每个方法论都附了对应的 skill（可被 agent 直接调用）。

> ⚠️ **一个诚实的提醒**：这本书是西方传统出版小说家写的，默认"单主人公 + 三幕结构 + 人物弧线"。你是写**网文**的话（超长篇、多线、爽感驱动），这些方法不能原样套——每个方法该在哪些地方打折扣，我都在"什么时候会失效"里标了，文末"作者的局限"一节也有总结。

## 一、先摆正心态：提纲不是牢笼，是航海图

**它解决什么问题**：你怕写提纲会束缚自己，或者你根本不知道提纲是什么、以为就是高中那种罗马数字大纲。

**核心逻辑**：提纲没有夺走"探索的乐趣"，只是把探索**提前**到了提纲阶段。它把左脑的逻辑工作（安排情节、查漏洞）前置，从而在写初稿时解放右脑去自由创作。但这一切有个前提——你必须把它当**指南而非铁律**：写到第十七章冒出更好的想法，就该抓住它，哪怕它不在原提纲里。

**书中的用法**：作者用《守望黎明》（写提纲→最优秀）和《梦境者》（不写提纲→8 个月烂稿）的正反对比，论证"先写提纲胜过返工"。

**什么时候会失效**：对斯蒂芬·金式的即兴型天才作家（书中自己也承认），预先规划未必更高效——尊重他们的路径，别把"写提纲"当普适真理。

## 二、定义你的小说：从"如果"到前提句

### "如果"问句——发散引擎

**它解决什么问题**：你只有一个模糊点子/人物经历，不知道怎么展开成故事。

**核心逻辑**：故意**疯狂地**列"如果 X 会怎样"的问句，不设限、不自我审查。多数站不住脚也没关系，它们的价值是打开想象力的阀门。进阶玩法是**读者期待法**：列出"读者会期待什么"，再决定满足还是颠覆，据此设计反转。

**书中的用法**：作者为《守望黎明》列了 13 条"如果"（"如果安兰不是骑士会怎样""如果她是刺客会怎样"），多数没用上，但"多亏了它们，想象力的阀门才打开"。

**什么时候会失效**：这是发散工具，不做收敛——收敛是下一步前提句的事。

→ 深入: [`what-if-brainstorm`](./what-if-brainstorm/SKILL.md)

### 前提句——一句话锁定小说

**它解决什么问题**：你有一堆点子，但讲不清"故事到底讲什么"，或不确定"点子能不能撑起一本书"。

**核心逻辑**：把发散成果压缩成**一句前提句**，同时锁定主人公（姓名/职业/个性）+ 主要冲突 + 大致情节。压不出来 = 想法还没想透。它是"迷你版提纲"，也是北极星，引导你后续所有提问。

**书中的用法**：作者把"如果我们的梦境真实存在会怎样"压成一句："记者克里斯发现：他入睡后会进入另一个世界，这世界正处在崩溃边缘，他别无选择，唯有拯救它。"——写出来后立刻知道下一步该问什么。

**什么时候会失效**：多线/群像小说一句话概括不了全书，可用前提句概括主线或第一卷。

→ 深入: [`premise-sentence`](./premise-sentence/SKILL.md)

## 三、画出小说示意图：盘点、标洞、连点

**它解决什么问题**：你脑子里一堆零散场景、片段，连不起来；或你发现情节有漏洞。

**核心逻辑**：把零散场景当作"连点成画"游戏里的点，分三步——①**列出**所有已知场景（不追求完整）；②**标出**讲不通、模糊的地方（这些空白就是情节漏洞）；③**连点成画**——挑最棘手的问题，用"如果/为什么"反复提问把点连起来。

**书中的用法**：作者列完《守望黎明》场景清单后，面对最棘手的"谁是安兰的敌人"，尝试"主教？""逃跑的僧侣？""好友冤死？"多种方案，最终找到一个讲得通的答案。

**什么时候会失效**：如果你连"点"都很少（素材几乎空白），先用"如果"问句发散，再回来连点。

## 四、核心元素：动机、冲突、主题

### 动机-愿望-目标链——人物的引擎

**它解决什么问题**：你的人物太平、读者不关心他、他的行动没有来由。

**核心逻辑**：人物的行动必须可追溯到一条**三级因果链**——动机（为什么想要）→ 点燃愿望（渴望什么）→ 引领目标（具体要得到什么）。关键洞见：**人物如何定义，取决于他想做什么，而非他做了什么**。

**书中的用法**：郝思嘉后半段一切举动都源于一句动机"我不要再饿肚子了"→ 渴望安全感 → 追求财富地位。

**什么时候会失效**：网文主角常以"能力/资源成长"代替"道德弧线"，愿望可改为变强/复仇/争第一，不必硬套道德成长。

→ 深入: [`character-engine`](./character-engine/SKILL.md)

### 制造冲突——在人物与目标之间加障碍

**它解决什么问题**：你的场景平淡、人物一路顺风、读者觉得无聊。

**核心逻辑**：知道了动机愿望目标后，制造冲突就简化为一个动作——**在人物与目标之间加障碍**。四张牌：①"最糟十事"生成器（写人物能遭遇的最糟的十种事）；②截止日期（给目标加期限，让读者听到倒计时）；③一张一弛（强度要有起伏）；④反派（放宽定义——任何阻碍目标的人都是反派，哪怕只是"点一杯拿铁"）。

**书中的用法**：《纳瓦隆大炮》把截止日期从几天压缩、中途又提前一天，把紧张感推到极致。

**什么时候会失效**：治愈系/日常向刻意追求平和，不是所有故事都需要高强度冲突。

→ 深入: [`conflict-engine`](./conflict-engine/SKILL.md)

### 主题发现——用人物轨迹挖主题，而非喊口号

**它解决什么问题**：你的小说好看但没深度；或你想表达一个观念但怕写成说教。

**核心逻辑**：主题不能贴标语，而是用**人物轨迹**把它"挖"出来。五个问题：主人公的内在冲突是什么？他的观念怎么变了？开头结尾如何用行动证明改变？能否用象征强化？如何用潜文本（未言明的话）印证？核心心法：**小说家的任务不是解答问题，而是提出问题**。

**书中的用法**：康拉德《吉姆爷》的"背叛的回响"主题，完全从吉姆弃船→羞愧逃离→最终不再苟活的行动轨迹里长出来，没人觉得他在说教。

**什么时候会失效**：纯爽文、图一乐，不强塞主题。

→ 深入: [`theme-discovery`](./theme-discovery/SKILL.md)

## 五、人物与背景：激发事件、幕后故事、采访、世界建构

### 激发事件——那扇"回不去了"的门

**它解决什么问题**：你的开头一直平淡，故事不知道从哪个事件真正开始。

**核心逻辑**：用**门测试**判定——问"主人公能否退回从前的安稳生活？"能，就还没踏入故事的门。激发事件不必是惨剧（搬家、新工作、遇到某人都算），但必须满足四特质：直接影响之后情节、制造冲突、抓住注意力、引发动作。一般放在小说**四分之一处或之后**。

**书中的用法**：《角斗士》里皇帝离世才是激发事件（此前皇帝提出继位只是铺垫），它引发继位、迫害、家人被杀等一系列不可逆事件。

**什么时候会失效**：网文要求"黄金三章"内出钩子，激发事件会大幅提前。

→ 深入: [`inciting-event`](./inciting-event/SKILL.md)

### 幕后故事冰山——挖水下的八分之七

**它解决什么问题**：你的人物没有过去、没深度，或只会写流水账式的身世。

**核心逻辑**：幕后故事是冰山水下的八分之七，是人物抉择的源头。探索别从出生顺写，而是**从激发事件倒推**。关键是挖出**点金石**——足以改变人生轨迹的大事件（如车祸、修道院经历），而非"出生于某地、大学、结婚、现在是会计"。使用时遵循铁律：**尽早暗示、最后一刻揭示、越短越好**。

**书中的用法**：作者挖出安兰"年轻时失手杀嫂、为赎罪当苦行僧"的过去，彻底改变了对人物和情节的理解。

**什么时候会失效**：网文主角的过去常简化为"金手指来历/复仇动机"，不必人人都有完整冰山。

→ 深入: [`backstory-iceberg`](./backstory-iceberg/SKILL.md)

### 人物采访——100+ 问 + 自由采访

**它解决什么问题**：你的人物平面，或写着写着忘了设定。

**核心逻辑**：用结构化问题清单（基本信息/人生观/外貌/性格/爱好/希望梦想）逐项采访人物，形成可回查的档案。常规采访失效时，用**自由采访**——直接以对白质问人物（"你为什么总逃避我？"），连续追问直到某个回答让你"啊"一声，那就是他连自己都没意识到的真实动机。

**书中的用法**：作者逼问一个逆来顺受的继女"为什么总是你承担一切"，最后逼出一句"如果她们不需要我，她们就不爱我了"——人物瞬间活起来。

**什么时候会失效**：快节奏下不必做全量 100 问，聚焦"核心需求 + 致命弱点 + 口头禅"更实用。

→ 深入: [`character-interview`](./character-interview/SKILL.md)

### 背景四问与世界建构

**它解决什么问题**：你的背景像贴上去的幕布，或要写架空世界但不知道从哪建起。

**核心逻辑**：先用**背景四问**检验价值——背景是否为有机组成部分？人物如何感知它？能否牵动情绪？是否过度使用？虚构世界再用**五维度问题集**自问（自然/社会/法则/居民/历史）。配套心法：**合众为一**（一个背景写透，好过走马观花六个）、为反复出现的背景铺线索。

**书中的用法**：《太阳帝国》的战俘营背景与小说融为一体，续作换成普通英国背景就失去了生命力——正反对比说明背景是"有机体"不是"配料"。

**什么时候会失效**：现实题材背景已明确，只需背景四问微调，不需五维度建构。

→ 深入: [`setting-worldbuild`](./setting-worldbuild/SKILL.md)

## 六、搭结构成稿：视角、三幕、逆向、精简

### 视角选择三问

**它解决什么问题**：你某个场景写出来没张力，怀疑是文笔问题。

**核心逻辑**：用三问选视角——①适量的视角（新视角非加不可才加）；②最恰当的视角（这一场景谁受冲击最大）；③最能打动人的视角（比较多个候选人）。关键反直觉点：场景卡住往往不是文笔，而是**选错了视角**。

**书中的用法**：作者一个"带坏消息"的场景怎么写都不对，最后发现"最悲痛的不是主人公"，换到坏消息触动最大的人物视角，张力立刻涌现。

**什么时候会失效**：网文群像多视角是标配，按"信息分配"而非"文学纯度"选视角。

→ 深入: [`pov-selection`](./pov-selection/SKILL.md)

### 开头-中间-结尾结构

**它解决什么问题**：你的故事中间拖沓、开头平淡、结尾收不住。

**核心逻辑**：三幕检查点——**开头**（引入主人公/展示日常/赋予愿望/创造激发事件并迫使他回应）；**中间**（多米诺失控/目标渐远/设新目标/被动转对抗）；**结尾**（自我认知深化/极限考验/最后一刻赋予力量/成长为英雄/经典语句作结）。再加三大基本元素（幽默/动作/关系）和**首尾呼应**。

**书中的用法**：作者随机抽三本风格迥异的小说，发现都有关系、动作、幽默感——三大元素是读者翻页的根本动力。

**什么时候会失效**：网文超长篇是"单元爽点 + 卷级高潮"循环，三幕应映射到单卷而非全书。

→ 深入: [`structure-three-act`](./structure-three-act/SKILL.md)

### 逆向提纲——卡住时从结局倒着写

**它解决什么问题**：你知道结局但不知道中间怎么连，正向写总是生硬。

**核心逻辑**：从更确定的终点 B 倒着推，持续问"如何发生/在哪/为什么/为何没死/怎么逃"，把每处空白变成一道**填空题**。填空比从零生造容易，因为你从已知结果反推必要条件，天然有逻辑连贯性。

**书中的用法**：作者知道人物"晚宴后受伤失联一个月"，从"受伤"倒推，填出"查尔斯派伏击、艾萨克相救"的完整链条，倒着写回了晚宴。

**什么时候会失效**：逆向的前提是"已知终点"；连结局都没定，先定终点。

→ 深入: [`reverse-outline`](./reverse-outline/SKILL.md)

### 两级提纲法——扩展版 → 精简版

**它解决什么问题**：你的提纲写了一大堆，写初稿时根本不想看；或场景太多不知道怎么删。

**核心逻辑**：两遍写提纲——**扩展版**（试验田，探索各种可能、标出问题）→ **精简版**（可读路线图，只留结论）。第二遍同时是过滤，含四件事：①**多米诺删减**（删掉"删了也不影响后续"的场景）；②**章节结尾 11 式**（每个结尾留一个"让读者想知道答案"的问题——预示冲突/秘密/誓言/震惊事件/激烈情绪/突转/新想法/未回答问题/神秘对白/预言/转折点）；③控制节奏（短章节快、长章节厚）；④砍脂肪（场景切换代替过渡描写）。

**书中的用法**：山德森《伊岚翠》用"场景切换"删掉反派爬云梯的过渡桥段，把可能 1400 页的作品瘦到 700 页。

**什么时候会失效**：精简版的前提是"已有扩展版提纲"，即兴创作者用不上。

→ 深入: [`condense-outline`](./condense-outline/SKILL.md)

## 陷阱与反例（作者警告的失败模式）

1. **把提纲当救命稻草、过于依赖**——提纲无法告知你一切，动笔后总有新盲点，要勇于调整。出版社要的"四十页提纲"早该动笔写初稿了。
2. **把提纲当铁律跑到底**——写到第五章发现女主人公的口角无法深化形象，就该立即改提纲；提纲是指南不是流水账。
3. **满足于"差不多"的点子**——不写提纲的人很难意识到自己的点子有多平庸；写提纲能逼你找到更好的点子。
4. **缺乏冲突**——人物在书页上漫无目的游走，是未出版作品最常见的问题。冲突 = 在人物与目标之间加障碍。
5. **说教式主题**——站在演讲台高谈阔论，读者最讨厌自以为是的作家。主题要通过人物轨迹不留痕迹地体现。
6. **流水账式幕后故事**——"出生于某地、大学、结婚、现在是会计"永远无法加深对人物的理解；要挖"点金石"大事件。

## 作者的局限（读这本书要打的折扣）

1. **时代局限**：2011 年成书，工具建议（yWriter/手写/纸质日历）在 AI 辅助时代已部分过时。她对手写的论证需重新评估。
2. **立场盲点**：她是西方传统出版小说家，方法论默认"单主人公 + 三幕结构 + 人物弧线是硬指标"。对**网文**（超长篇、多线、金手指/爽感驱动）适配有限——爽感逻辑、升级打怪、日更连载都不在她的框架内。
3. **未证明的假设**：核心假设"预先规划一定比边写边想更高效"主要由她个人经历支撑，对即兴型天才作家（书中承认的斯蒂芬·金、阿特伍德）不必然成立。
4. **幸存者偏差**：她只统计了"写提纲后成功的自己"，没有统计"不写提纲也成功的别人"。计划者与即兴者同样高产，提纲的"普适性"主张可能站不住。

## 关键术语速查

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 提纲 | 小说的"航海图/指南"，可长可短、可随时改道 | ≠ 高中罗马数字大纲，那恰是作者反对的 |
| 前提句 | 一句话锁定人物+冲突+情节的"迷你版提纲" | ≠ 故事简介，它必须锁死三要素 |
| 如果问句 | 故意疯狂、不设限的发散引擎 | ≠ 逻辑推演，它只发散不收敛 |
| 激发事件 | 颠覆人物世界、不可逆的"门" | ≠ 任何重要事件，门槛是"回不去" |
| 幕后故事 | 冰山水下的八分之七，人物抉择的源头 | ≠ 可随意倒出的背景，要"早暗示晚揭示" |
| 多米诺效应 | 每个场景是骨牌，删"删了也不影响后续"的 | ≠ 场景堆砌，填充物可能是关键骨牌 |

完整词典见 [GLOSSARY.md](./GLOSSARY.md)。

## 如果只带走三句话

1. **提纲是指南不是铁律**——它不束缚你，反而把探索乐趣提前、把返工风险降为零，前提是写到中途敢改。
2. **小说的引擎 = 人物的愿望 + 追求愿望途中的障碍**——制造冲突就是"在人物与目标之间加障碍"。
3. **先发散、后收敛、再精简**——"如果"问句发散 → 前提句收敛 → 扩展版提纲 → 精简版路线图，两遍成稿。
