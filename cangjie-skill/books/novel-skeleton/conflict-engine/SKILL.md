# 制造冲突（人物与目标之间加障碍）

## R — 原文 (Reading)

> "当你知道了人物的动机、愿望和目标时，制造冲突不过是在人物与目标之间添加障碍罢了……对人物而言，他所能遭遇的最糟糕的事是什么？设法写出十种可能。"
>
> — 凯蒂·维兰德，第五章

---

## I — 方法论骨架 (Interpretation)

知道了人物的动机、愿望、目标之后，制造冲突就简化为一个动作：**在人物与目标之间添加障碍**。四张可反复用的牌：

1. **最糟十事**：问"人物能遭遇的最糟糕的事是什么"，快速写十种，不行再写十种。
2. **截止日期**：给目标加期限，让读者听到"嘀嗒嘀嗒"的倒计时。
3. **一张一弛**：冲突强度要有起伏，穿插平和场景，别一味红色警报。
4. **反派**：放宽定义——任何阻碍目标实现的人都是反派（哪怕只是"点一杯拿铁"）。

进阶：每个场景应**兼备内在冲突**（心理波动）与**外在冲突**（外部对抗），最有力的结局让两者同时达到高潮碰撞。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《纳瓦隆大炮》的截止日期
- **问题**: 二战片中，一群人去摧毁德军大炮，怎么保持紧张？
- **方法论的使用**: 设硬截止日期（几天内完成，否则两千英军全军覆灭），中途还把日期提前一天。
- **结论**: 时间紧迫感把节奏提升到另一个层次。
- **结果**: 观众全程屏息。

### 案例 2: 2003 版《彼得潘》的双冲突碰撞
- **问题**: 如何让结局不只是"打赢海盗"这么单薄？
- **方法论的使用**: 外在冲突（斗虎克船长）与内在冲突（与内心恶魔较量）同时推到高潮。
- **结论**: 外在内化、内在赋深，两种冲突互为补充。
- **结果**: 谱写出令人难忘的结局。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户觉得自己的场景平淡、无波澜。
2. 用户写的人物一路顺风顺水，读者觉得无聊。
3. 用户想给人物设置挫折，但只会"车祸/死亡"等老套路。
4. 用户要评估"我每个场景有没有足够的冲突"。

### 语言信号

- "我的小说没冲突""太平淡""读者说无聊"
- "怎么让人物受挫""冲突太弱了""不会制造冲突"
- "no conflict""flat""how to create tension"

### 与相邻 skill 的区分（初稿）

- 与 `character-engine` 的区别: 那是"人物想要什么"，本 skill 是"怎么阻止他得到"。
- 与 `theme-discovery` 的区别: 内在冲突常承载主题，但主题发现重在"挖观念"，本 skill 重在"造障碍"。

## E — 可执行步骤 (Execution)

1. **确认人物的目标**（来自 character-engine）。
   - 完成标准: 目标具体到可以被"阻碍"。

2. **列出人物与目标之间的障碍**（用最糟十事生成器，写 10 种）。
   - 完成标准: ≥10 种，含 2 种以上非套路（不只有死亡/车祸）。

3. **给关键目标加截止日期**。
   - 完成标准: 至少一个目标有明确期限和"做不到的代价"。

4. **检查每个场景的内外冲突 + 强度起伏**。
   - 完成标准: 每个场景能标注"外在冲突 + 内在冲突"，且整体强度有张有弛。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 合作型/治愈型/日常向场景刻意追求平和——不是所有故事都需要高强度冲突。
- 用户要的是"人物内心挣扎的弧线"（更偏 theme-discovery），不是"外部障碍"。

### 作者在书中警告的失败模式

- **缺乏冲突**：人物在书页上漫无目的游走，是未出版作品最常见的问题。
- **冲突拖沓**：人物生活快乐祥和 = 挫折太少（除非刻意写"暴风雨前的宁静"）。
- **无节制冲突**：一味高强度没有喘息，读者会厌倦；开头就把苦难抖完，结尾无墨可写。
- **人物冲突无理由**：两人突然大打出手却没有合理缘由，读者不信。

### 作者的盲点 / 时代局限

- "每个场景都要有冲突"是西方戏剧传统；网文有大量"升级/装逼/爽点"场景，冲突的"障碍"形式不同（金手指 vs 反派的资源碾压），需翻译而非照搬。

### 容易混淆的邻近方法论

- 与"悬念设计"的区分: 冲突是"障碍/对抗"，悬念是"预期/未知"，两者可组合但不同。
