# 提纲心态（指南非铁律）

## R — 原文 (Reading)

> "正如《加勒比海盗》中的海盗准则一样，提纲更多的是一种指南。好的提纲应激发我们的创造力而非成为我们的绊脚石；作家是提纲的缔造者而非奴隶。"
>
> — 凯蒂·维兰德，第一章

---

## I — 方法论骨架 (Interpretation)

提纲不是把你锁死的牢笼，而是一张航海图：它帮你动笔前看清全局、避开死胡同、免去写完十万字后的返工。它没有夺走"探索的乐趣"，只是把探索**提前**到了提纲阶段；它把左脑的逻辑工作前置，从而在写初稿时解放右脑去自由创作。

但一切好处都有一个前提——你必须把它当**指南而非铁律**：写到第十七章冒出更好的想法，就该抓住缪斯，哪怕它不在原提纲里。衡量一种提纲方法对不对，唯一标准是"它是否给你最大的创作自由"。

这是整套流水线的元框架：先摆正心态，再谈具体工序。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《守望黎明》写提纲 → 最优秀小说
- **问题**: 作者此前从不写正式提纲，写作依赖"时有时无的创造力"。
- **方法论的使用**: 花三个月写提纲，构思并设计场景，作为路线图。
- **结论**: 提纲让她动笔前就看清关键节点、把握宏观结构。
- **结果**: 《守望黎明》一举成为她当时最优秀的小说，"小说如流水般自然涌出"。

### 案例 2: 《梦境者》不写提纲 → 8 个月烂稿
- **问题**: 写完《守望黎明》后，作者又绕回老路，没写提纲就动笔下一部。
- **方法论的使用**: 无地图地"驶向写作荒原"。
- **结论**: 50 页写满布局凌乱、情节散乱，只得回头补写提纲。
- **结果**: 8 个月写 50 页 + 返工 3 个月，近一年时间白费。她说"花点时间写提纲，总比给十万多字动手术好得多""我写提纲主要是因为我懒，我痛恨改写"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户准备开书/写长篇，但纠结"要不要先写提纲"。
2. 用户对提纲有抵触："提纲会束缚我的创造力""我不想被框死"。
3. 用户是新手，不知道"提纲"到底指什么、是不是高中那种罗马数字格式。
4. 用户刚写完一部烂尾/返工惨重的稿子，来问"怎么避免下次再这样"。

### 语言信号

- "要不要写提纲？""大纲有用吗？""写提纲会限制我吗"
- "我写东西就是不想提前想好，喜欢边写边发现"
- "提纲是不是就是 I./a./i. 那种死板的东西"
- "Should I outline?" / "will outlining kill my creativity?"

### 与相邻 skill 的区分（初稿）

- 与 `novel-outline-pipeline`（总编排）的区别: 本 skill 只解决"认知/心态"问题，不执行具体工序；总编排负责把整套工序串成流程。
- 与 `what-if-brainstorm` 等的区别: 本 skill 是"要不要写、怎么写才对"的元问题，其它是"具体写哪一步"。

---

## E — 可执行步骤 (Execution)

1. **破除四条错误认知**（格式严格 / 束缚创造力 / 夺走探索乐趣 / 太耗时）。
   - 完成标准: 用户能用自己的话说出"提纲无固定格式、是指南非铁律"。

2. **用成本账评估"要不要写提纲"**。
   - 完成标准: 用户明确"先规划"还是"先写再改"，并知道各自的代价（写提纲花时间 vs 返工花更多时间）。
   - 判停条件: 若用户明确是即兴创作型且拒绝规划 → 跳到步骤 4，不强推。

3. **确立"指南非铁律"的底线**。
   - 完成标准: 用户认可"写到中途有更好想法就调整提纲"。

4. **把用户交给流水线下一道工序**（`what-if-brainstorm` / `premise-sentence`）。
   - 完成标准: 用户已摆脱对提纲的恐惧，愿意进入具体工序。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已是成熟计划者，只问"某一步具体怎么写"——那交给对应工序 skill。
- 用户明确是斯蒂芬·金式的即兴型天才且强烈抵触规划——尊重其路径，别把"写提纲"当普适真理。

### 作者在书中警告的失败模式

- **把提纲当救命稻草、过于依赖**（贝琪·莱文）：提纲无法告知你一切，动笔后总有新盲点，要勇于调整。
- **把提纲写得冗长到榨干生命力**（约翰·罗宾孙）：出版社要的四十页提纲，早该动笔写初稿了。
- **罗马数字式死板提纲制造隔阂**（阿吉·维拉努瓦）：枯燥的格式会在作家与作品之间制造隔阂。

### 作者的盲点 / 时代局限

- 作者默认"预先规划一定比边写边想更高效"，但这主要由她个人经历支撑——对即兴型作家（书中自己承认的斯蒂芬·金、玛格丽特·阿特伍德）并不必然成立。
- "写提纲具有普适性"可能是**幸存者偏差**：她只统计了"写提纲后成功的自己"。

### 容易混淆的邻近方法论

- 与"列大纲 = 死板规划"的误解: 本 skill 的立场是"提纲带来自由"，与"规划=束缚"的直觉相反。
