# 术语词典 — 《小说的骨架：好提纲成就好故事》

> 本书由 cangjie-skill 蒸馏。本词典是全部 16 个 skill 的**共享术语层**：凡引用下列词，一律以"作者用法"为准，不得按字典义/常识义使用。

## 核心概念

### 提纲 (outline)
- **作者的用法**: 小说的"地图/路线图/指南"，形式自由、可长可短、可随时推翻改道。本质是让灵感与结构同时在场。
- **和常识的差异**: ≠ 高中罗马数字式大纲（Ⅰ./a./i.）——那恰恰是作者反对的；≠ 束缚创造力的牢笼——它反而是"创作自由"的来源。
- **为什么重要**: 全书中心词。若按"正式的章节计划表"理解，会把提纲写成死板目录、不敢推翻。

### 前提句 (premise sentence)
- **作者的用法**: 用一句话同时锁死人物 + 主要冲突 + 大致情节的"迷你版提纲"；既能验证想法是否可行，又能"引导你找到下一个问题"。
- **和常识的差异**: ≠ 故事简介/营销文案——它必须锁死三要素；≠ 灵感记录——它是对灵感的"可行性质检"。
- **为什么重要**: 所有下游 skill 的第一步产出；若当简介写，会把"验证想法"降级为"包装想法"。

### 如果问句 (what-if)
- **作者的用法**: 故意疯狂、不设限地列"如果 X 会怎样"的联想引擎，是前提句的原料。
- **和常识的差异**: ≠ 逻辑推演/现实沙盘——它只负责发散，不负责收敛；即使"有想法行得通也不要轻易满足，继续发问"。
- **为什么重要**: 头脑风暴类 skill 需区分"发散期（禁止筛选）"与"收敛期（严格筛选）"两阶段。

### 小说示意图 (scene map)
- **作者的用法**: 提纲的全景展示——列出已知场景的"点"，标出点与点之间的空白（情节漏洞），再连点成画。
- **和常识的差异**: ≠ 完整场景描写/分镜——它只求"点的分布"与漏洞；是"找洞工具"而非"成稿预览"。
- **为什么重要**: 结构诊断类 skill 要把它当"找漏洞的全景图"使用，而非场景精修清单。

### 激发事件 (inciting event)
- **作者的用法**: 打翻第一张多米诺骨牌、颠覆人物世界、不可逆的事件；门槛是"无法回到从前"（贝尔的"门"）。
- **和常识的差异**: ≠ 任何重要事件/开篇大场面——四特质（影响情节/制造冲突/抓注意力/引发动作）；≠ 一定在开头（作者主张四分之一处或之后）。
- **为什么重要**: 结构类 skill 用它判断"开篇是否真的启动了故事"。

### 幕后故事 (backstory)
- **作者的用法**: 小说开始之前的故事，是人物一切抉择与动作的源头；海明威冰山——水下的八分之七是根基，但只露八分之一。
- **和常识的差异**: ≠ 可随意倒出的背景资料——正确用法"早暗示、晚揭示、越短越好"；它是写给自己的人物根基，绝大部分永不入文。
- **为什么重要**: 避免信息倾倒、摧毁悬念。

### 动机、愿望与目标 (motivation / desire / goal)
- **作者的用法**: 三级链条——动机点燃愿望，愿望引领目标；目标是愿望的"可执行形态"。
- **和常识的差异**: ≠ 三者等同；动机是读者看不见的"为什么"，是设置障碍、产生冲突的入口。
- **为什么重要**: 缺了链条，人物行动显得无根，"给目标设障碍"也无从谈起。

### 内在冲突与外在冲突 (internal / external conflict)
- **作者的用法**: 每个场景都应两者兼备（内在：内心舞台；外在：外部对抗），最强结局让两者高潮同时碰撞。
- **和常识的差异**: ≠ 二选一的冲突类型——而是"每场景双冲突 + 高潮对撞"的可执行检查项。
- **为什么重要**: 冲突制造类 skill 若只给外在对抗，人物会平。

### 多米诺效应 (domino effect)
- **作者的用法**: 每个场景是一张多米诺骨牌，必须影响后续场景；删场景的判据是"删掉也不影响后续的，才删"。
- **和常识的差异**: ≠ 场景堆砌；≠ "看似无关的场景就不重要"——填充物可能是关键骨牌（杜穆里埃的修女）。
- **为什么重要**: 删减类 skill 用"影响链"而非"看着是否重要"做判据。

## 方法 / 技法

### 逆向提纲 (reverse outline)
- **作者的用法**: 当"不知道下一个多米诺骨牌是什么、难以下笔"时，从已知结局倒推每一步"为什么会这样"，把未知变成可填的空。
- **和常识的差异**: ≠ 常规线性提纲的反向排版；≠ 只适用于开头——专治"A 到 B 不知道怎么写"的任何卡壳处。
- **为什么重要**: 最独特的可迁移技巧，卡壳时的第二套武器。

### 扩展版提纲 (expanded outline)
- **作者的用法**: 小说布局的"试验田"——收罗千奇百怪的想法与死胡同，遇见薄弱处就停下来应对。
- **和常识的差异**: ≠ 正式成稿的骨架；≠ 初稿时的参考物（它含大量"如何得出结论"的过程文字）。
- **为什么重要**: 别把详版当交付物，否则写作时信息过载。

### 精简版提纲 (condensed outline)
- **作者的用法**: 从扩展版提炼出的"过滤后只留结论"的可读路线图，是写初稿时的工作指南。
- **和常识的差异**: ≠ 扩展版的缩略摘要——它剔除过程文字，只留站点与目的地。
- **为什么重要**: 写作时喂扩展版会带大量死胡同信息，精简版才是工作指南。

### 首尾呼应 (bookending)
- **作者的用法**: 在开头植入具体的人物/场景/主题意象，结尾应答；必须在写提纲时就有意安排。
- **和常识的差异**: ≠ 空泛的"主题回声"——是具体可指认的元素，可被刻意安排。
- **为什么重要**: 连贯性检查类 skill 的可操作定义。

### 完美评述 (perfect review)
- **作者的用法**: 动笔前，想象一位完全读懂你脑中书的评论家，写下他如何评价这本书（具体/全面/满足）。
- **和常识的差异**: ≠ 故事梗概/客观自评——用"未来评论家"视角绕过"作家无法客观评价自己构想"的困境。
- **为什么重要**: 把"模糊想法"变成可评估的愿景目标（已并入 outline-mindset 作可选步骤）。

### 人物采访 (character interview)
- **作者的用法**: 用 100+ 具体刁钻的问题深入了解人物（比读者更了解他），答案绝大部分不直接进正文。
- **和常识的差异**: ≠ 填一份性格问卷——目的是让幕后故事沉在冰山之下。
- **为什么重要**: 把扁平人设做成"活人"。

### 左右脑分工 (left/right brain)
- **作者的用法**: 工作流隐喻——构思（右脑）→写提纲（左脑）→创作（右脑）→修改（左脑）；把左脑的单调逻辑工作前置到提纲阶段。
- **和常识的差异**: ≠ 神经科学意义上的左右脑学说——是解释"写提纲不伤害创造力"的工作流隐喻。
- **为什么重要**: 写作/修改阶段应各用各脑（创作时少做结构评判，修改时少求灵感）。

### 截止日期 (deadline)
- **作者的用法**: 给小说内部人物的目标设"倒计时"（即使目标只是去杂货店购物也要有期限），是制造惊险最简单的方法。
- **和常识的差异**: ≠ 作者的写作计划——是小说内部给人物的期限；≠ 只适合悬疑。
- **为什么重要**: 区分"给人物设期限"（制造冲突）与"给自己设期限"（写作纪律）。

### 迷你反派 (mini-antagonist)
- **作者的用法**: 在小范围内制造冲突的次要人物（本可迎合主角、却被注入反叛基因），低成本的冲突来源。
- **和常识的差异**: ≠ 正式大反派——它不改变主线格局，却可在日常穿插制造冲突。
- **为什么重要**: 冲突类 skill 常只教"造大反派"，迷你反派更易部署。
