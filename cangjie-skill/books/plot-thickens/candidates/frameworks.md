# ===== 第4章 经历（全书哲学核心）=====

- id: f01
  title: 旅程优先于目的地（信息保留原则）
  type: framework
  source_chapter: 第4章 经历
  source_quote: |
    "当你开始讲故事时，你会发现第一件事不是决定透露哪些信息，而是决定保留哪些信息；你传播信息的方式比信息本身更重要。读者或观众正是在这个信息传播的过程中获得满足感的……目的地远没有旅程来得重要。"
  summary: |
    面对一个目标/信息/结局，不要先问"要传达什么"，而要先问"保留什么、以什么路径传达"。
    满足感来自信息传播的过程，而不是信息本身——所以作家的第一决策是"保留"，而非"透露"。
    迁移：演讲节奏、产品发布、教学设计、悬念营销——先设计信息释放的节奏，再设计内容本身。
  tags: [information-design, pacing, journey-over-destination]

- id: f02
  title: 深度经历三层递进模型
  type: framework
  source_chapter: 第4章 经历
  source_quote: |
    "深度经历1：认识他人……深度经历2：认识自我……深度经历3：在认识的基础上采取行动……在认识的基础上采取行动是所有经历中最深刻的。在这种经历结束时，人物彻头彻尾地变成了另一个人，完全认不出来了。"
  summary: |
    真正改变一个人的经历分三层递进：
      ① 认识他人（看清真相，但治标不治本，易重蹈覆辙）
      ② 认识自我（承担个人责任，设立新边界）
      ③ 在认识基础上行动（最深刻、最难，让人彻底变成另一个）
    每上一层都更深刻但更难达成；停在第一层是"觉醒了却重复旧模式"的常见困境。
    迁移：行为改变、成瘾治疗、组织变革、人物弧线诊断——用三层判定"真的变了还是只是看清了"。
  tags: [change-model, layered-depth, behavior-change, character-arc]

- id: f03
  title: 表面经历7类生成器（vs 深度经历）
  type: framework
  source_chapter: 第4章 经历
  source_quote: |
    "下面列出七种常见的表面经历（按照它们改变人物生活的速度排序）……恋爱、物质、身体状况、友谊、知识、名望、家庭。这些经历很容易被误解成深度经历。它们不是。"
  summary: |
    7种社会普遍接受、能快速可信地改变人物的表面经历：恋爱/物质/身体状况/友谊/知识/名望/家庭。
    它们易得但浅，常被误当作深度经历；最大价值是作为"引导入口"——尤其消极的"失去"类（失去地位/失去家庭/破产）更容易激发自我认识的深度经历。
    短媒介（300页/2小时）要在不徐不急中完成人物转变，必用此生成器。
    迁移：人物快速变化工具箱；任何"短时间呈现成长"的场景（demo day、汇报、短文）。
  tags: [experience-generator, surface-vs-depth, character-change]

- id: f04
  title: 认识-行动矛盾紧张器
  type: framework
  source_chapter: 第4章 经历
  source_quote: |
    "认识和行动之间是有可能存在矛盾的——事实上，这经常存在。不要急于解决这种矛盾……你可以利用甚至延长这种矛盾，从而创造出一种最深刻的紧张感。人物知道正确的行动是什么，但是不确定他是否要那样做。"
  summary: |
    当人物"知道正确做法却做不到"时，不要急于解决这个矛盾，而要延长它。
    延长此矛盾会创造最深刻的紧张感，并衍生：神经官能症（心理投射/偏执/生理症状）、道德困境（救家人还是杀外人）、悲剧（决定行动却已太晚，如《汇流》）。
    极端版：人物永远无法解决此矛盾——作品研究"为什么人无法行动"。
    迁移：内心戏/道德两难/反英雄的可操作机制；真实决策中的"知行 gap"诊断。
  tags: [tension-generator, moral-dilemma, inner-conflict, knowing-doing-gap]

- id: f05
  title: 经历编织术（多经历关系学）
  type: framework
  source_chapter: 第4章 经历
  source_quote: |
    "在《洛奇》中……他的第二段经历（心理复健）影响了他的第一段经历（身体训练）……这些经历在恰当的时机平行展开……它们就像接力赛选手的交接棒一样。最终把故事推向结局的是洛奇的女朋友。"
  summary: |
    多段经历的关系类型决定故事质地，4种基本关系：
      ① 相辅相成（接力棒）：A 经历卡住时 B 接力推动
      ② 相互冲突：积极经历（成名）把人物推向消极（自大/毒品）——最强，能强制开启深度经历
      ③ 平行滋养：两段经历互相供给养分，交汇于同一终点
      ④ 开启新纪元：经历结束时自然激发新经历（续集逻辑）
    设计原则：相互依存的经历 > 单一经历；冲突的经历 > 和谐的经历。
    迁移：长篇结构/产品路线图/多线程人生的弧线规划。
  tags: [multi-arc-weaving, story-structure, experience-interaction]

# ===== 第5章 悬念 =====

- id: f06
  title: 悬念生成器（12式上位框架）
  type: framework
  source_chapter: 第5章 悬念
  source_quote: |
    "悬念是关于预期的……悬念就是创造和延长预期。如何制造悬念要复杂得多。悬念由许多层层递进的元素构成……让我们从创造预期开始，先来看12个最明显的步骤。"
  summary: |
    悬念的本质 = 创造并延长预期（不是"可怕的事情"本身，而是"它还没发生"的过程）。
    12个生成元素（任选 1-3 组合即可为普通场景注入张力）：
      目标 / 提高筹码 / 危险 / 滴答时钟 / 无能为力 / 未知 /
      爱情张力 / 戏剧反讽 / 生活在未来 / 悬而未决 / 秘密 / 人物类型
    两个关键约束：
      ① 悬念应从人物和环境自然产生，不应倒置为目的（否则就是廉价钩子）
      ② 重要性是相对的——目标对人物的渴望度决定筹码，而非目标的客观价值
    真正独特的子机制见 f07-f10（戏剧反讽/延长/滴答时钟/无能为力）。
    迁移：任何需要"让人放不下"的场景——开会、文案、 demo、演讲。
  tags: [suspense-generator, expectation-creation, list-synthesized, master-framework]

- id: f07
  title: 延长悬念（拉伸预期的艺术）
  type: framework
  source_chapter: 第5章 悬念
  source_quote: |
    "好的作家知道如何制造悬念；最好的作家知道如何延长它……希区柯克让杀手的到来缓慢得令人难以忍受……他握着王牌……为了延长期待，他把杀手的到来拉伸到了电影中的30秒。"
  summary: |
    制造悬念只是开始；真正的高手是延长它。许多作家艰难创造出强悬念，却只发挥了一半。
    延长技术：
      ① 拉伸场景的叙述时间，接近真实时长（5 秒炸弹就数 5 秒）
      ② 分心 / 打断 / 欲言又止 / 沉默 / 错误的开始
      ③ 多层悬而未决叠加（16 条未听留言 + 还没说出口的大新闻 + 妻子也有秘密）
      ④ 把单一悬念场景拆成两段，用悬而未决连接（肥皂剧钩子机制）
    平衡：延长过久会让读者挫败而放弃；过短则浪费王牌。
    迁移：谈判节奏、演示节奏、教学悬念、销售推进的时机控制。
  tags: [suspense-extension, pacing, expectation-stretching]

- id: f08
  title: 戏剧反讽（读者独知的悬念）
  type: framework
  source_chapter: 第5章 悬念 + 第7章 上下文
  source_quote: |
    "'戏剧反讽'是指我们作为读者或观众，知道一些人物自己不知道的事——通常是会对他们造成影响的事……这是一种特殊的悬念——只为我们设计的悬念。它非常有效。"
  summary: |
    当读者拥有人物不知道、且会影响人物的关键信息时，产生"只为读者设计"的特殊悬念。
    力量来源：
      ① 积极调动观众（想出声示警）
      ② 让观众感觉掌握故事全貌
      ③ 同情方向可随"谁知道什么"切换（丈夫知情 vs 妻子知情 vs 餐馆下毒——三种完全不同的同情）
      ④ 支撑喜剧（误解类）和悲剧
    本质：戏剧反讽是基于上下文的——同一信息改变"谁知道它"，就改变整个场景的意义。
    迁移：信息不对称的叙事；产品演示中"先告知观众而角色不知"的反差设计。
  tags: [dramatic-irony, information-asymmetry, audience-engagement, context-dependent]

- id: f09
  title: 滴答时钟（时间压力化）
  type: framework
  source_chapter: 第5章 悬念
  source_quote: |
    "加入时间限制对于制造悬念大有帮助……滴答作响的时钟不一定是字面意义上的真正的钟。纵观你的作品，问问自己，时间到底经过了几天、几星期或者几个月……大部分作品中的故事本来可以发生在更短的时间内。"
  summary: |
    给目标加上时间限制是放大悬念的强力工具，且时间不一定是字面钟表。
    三个操作：
      ① 把故事的"经过时间"显性化——问"几周还是几天？"多数作品的经过时间可以大幅压缩，压缩本身注入紧迫感
      ② 关键场景让叙述时间 ≈ 真实时间（5 秒炸弹就数 5 秒）
      ③ 给单场景或整部作品加上硬时间限制（24 小时救总统）
    关键：时钟本身不增加悬念——悬念取决于人物如何"使用"时钟（盯着表针 vs 不看表）。
    迁移：任何任务/项目/情节的紧迫感设计；防止"无限延期"的项目管理工具。
  tags: [ticking-clock, time-pressure, urgency-design]

- id: f10
  title: 无能为力（行动阻断）
  type: framework
  source_chapter: 第5章 悬念
  source_quote: |
    "最有效地制造悬念的方法之一是让人物有一个重要的目标，却无法采取行动。停车场里，一名杀手向女孩走去。女孩拼命转动钥匙，却怎么也打不开车门……如果他能够从防火梯逃走，悬念就不存在了。"
  summary: |
    让人物有强烈目标却无法行动（身体/智力/心理/精神上的无力）是最有效的悬念制造法之一。
    无力的四种类型：
      ① 身体被困（断腿、打不开车门、沉船上的人）
      ② 智力不足（忘记密码、被算计无法回应）
      ③ 心理干预失效（母亲救不了抑郁儿子）
      ④ 精神上无力（神父安慰不了丧子女人）
    也可扩展：预见未来却无人相信（《死亡地带》）；对他人构成无力避免的危险（杀手视角）。
    紧张感的本质 = 重要目标 + 行动路径被切断。
    迁移：紧张场景的本质解构——你的主角为什么"不能直接做"？
  tags: [powerlessness, helplessness, action-blocked]

# ===== 第6章 冲突 =====

- id: f11
  title: 冲突生成器（13式上位框架）
  type: framework
  source_chapter: 第6章 冲突
  source_quote: |
    "冲突有许多种功能：它要求读者选择立场；它制造裂痕然后为圆满解决铺平道路；它帮助制造悬念；它让作品具有方向感……有数不清的冲突形式——让我们来了解13种最基本的方法。"
  summary: |
    冲突的本质 = 对抗，是"选择"背后必然存在的张力（无冲突选项 = 无选择）。
    13种生成器：人物 / 群体 / 被迫在一起 / 冲突的目标 / 提高筹码 / 权力斗争 /
                竞争 / 时间 / 家庭 / 恋爱 / 工作 / 态度 / 内心
    冲突的功能远不止破坏：
      ① 强制读者/观众选立场
      ② 为圆满解决铺路
      ③ 制造悬念和方向感
      ④ 让人物"显形"——谁发起、谁斡旋、谁退缩都是性格暴露
    两个关键约束：
      ① 冲突应从人物自然产生，环境只是放大器（若需极端环境才能造冲突，说明人物塑造失败）
      ② 冲突不能太快解决（悬念消失）也不能永久（读者悬而未决）
    真正独特的子机制见 f12（内心冲突最高形式）。
    迁移：任何需要暴露真实关系的场景——团队、家庭、产品冲突、用户访谈。
  tags: [conflict-generator, opposition-creation, list-synthesized, master-framework]

- id: f12
  title: 内心冲突最高形式论
  type: framework
  source_chapter: 第6章 冲突
  source_quote: |
    "冲突的最高形式通常来自内心。外部冲突至少是可以言说的，可以被解决、避免和忽略；内心冲突却不容易贴上标签，从来不能避免，有时候永远不能解决……我们经常渴望——甚至制造——外部冲突，以便不去思考内心冲突的问题。"
  summary: |
    冲突的最高形式 = 内心冲突，因为它是不可避、不可解、不可言说的。
    一个反直觉推论：人会无意识地制造外部冲突，以逃避内心冲突——
    所以观察一个人反复卷入的外部冲突模式，就能反推他未解决的内心议题。
    一个人的内心冲突越激烈，他制造的外部冲突就越严重（成瘾、吵架狂、危机依赖者）。
    极端化：不可解决的内心冲突真能把人逼疯。
    迁移：角色深度诊断；真实人物的心理画像；自我觉察——"我反复和谁/什么冲突？指向什么内心议题？"
  tags: [inner-conflict, projection-theory, character-depth, self-diagnosis]

# ===== 第7章 上下文 =====

- id: f13
  title: 上下文宏观编辑（俯瞰视角）
  type: framework
  source_chapter: 第7章 上下文
  source_quote: |
    "没有什么是独立存在的，所有的元素都要根据它最终在多大程度上有助于（或有损于）其他元素来评判……上下文要求相反的东西：你必须从宏观上审视你的作品。这时你需要的是俯瞰的视角。"
  summary: |
    局部优秀的元素可能损害整体。上下文编辑要求切换到俯瞰视角，三步法：
      ① 逐元素问"它对其他元素是助益还是损害？"——再美的场景若重复主题也必须删
      ② 找重复（最常见也最隐蔽的编辑问题）：
         - 单词/句子重复易识别
         - 主题/环境/目的的模糊重复最难识别（需一口气读完专门找）
         - 但有时读者需要重复（提醒 + 主题共鸣，如《教父》开场与结尾呼应）
      ③ 用对比衬托（鬼屋后的晴天才是天堂；监狱题材很少始终在监狱里）
    必备工具：时间隔离（隔两周再读）+ 局外人视角。
    迁移：任何复杂系统的整体性 review——产品设计、架构审查、论文修改、年度复盘。
  tags: [macro-edit, holistic-review, context-judgment, repetition-detection]

- id: f14
  title: 篇幅分配=作品真正主题
  type: framework
  source_chapter: 第7章 上下文
  source_quote: |
    "篇幅分配是你的总体规划，它比任何其他东西都更能反映你的故事是关于什么的……作家对作品的特定方面投入有多深，会极大地影响作品的节奏、进展、焦点和终极意义。"
  summary: |
    别问作家"作品是关于什么"——看他分配的篇幅。篇幅是无意识的总体规划，比任何宣言都更真实。
    自检用法：
      ① 作品层：我花最多篇幅的人物/场景/主题，是不是我真的想说的事？
      ② 人生层：我花最多时间/注意力的事情，是不是我真的认为重要的事？
      ③ 文档/演讲层：最长的那一段，是否对应最重要的论点？
    常见陷阱：作家在没决定"关于什么"时就开始写，结果是篇幅失衡——必须修改成型。
    迁移：用"时间/字数分配"反向审计任何创作的真实优先级，包括自己人生。
  tags: [allocation-truth, priority-audit, implicit-theme, self-diagnosis]

# ===== 第8章 超越 =====

- id: f15
  title: 阅读心理曲线4阶段（影响力标尺）
  type: framework
  source_chapter: 第8章 超越
  source_quote: |
    "理想的作品可以让读者经历四个阶段：好奇→兴趣→需要→行动……你能唤起读者的最高层次就是让他们因为作品而感动，仅仅读完这本书或看完这部电影还不够；你能够把一种将他们读到或看到的东西付诸行动的热望植入他们心中。"
  summary: |
    作品（或任何传达）的影响力分4个递进阶段，越后越难达到：
      ① 好奇（最易，营销可达成；陌生人愿意给你2小时）
      ② 兴趣（被吸引不想离开，但还没决定看完）
      ③ 需要（全方位需要，非短期"想知道结局"——标志是足够强的代入与未解问题）
      ④ 行动（改变实际行为，如给国会写信、发动暴乱——终极力量）
    后阶段必须建立在前阶段上；大多数作品停在好奇或兴趣层。
    自检：作品激发他人到了哪一层？1-10 打几分？
