# 《情节》— 关键概念词典（Glossary）

> cangjie-skill 阶段 1 产出。本文件不独立成 skill，作为所有下游 skill 的共享术语基线。
> 术语定义严格采用卢克曼在书中的用法；`key_distinction` 字段说明与常识用法的差异，是最有价值的字段。
> 全部条目基于源文本 `qingjie-full.md`（2254 行）蒸馏，附原文行号便于回溯。

## g01 · 经历 (experience)

```yaml
- id: g01
  term: 经历
  en: experience
  type: core-concept
  source_chapter: 第 4 章（全书哲学核心）
  frequency: 255 次（全书最高频概念之一）
  author_definition: |
    "他的接下来的行动将构成情节的主体——他的经历。描写那些处在变化边缘的人物，
    那些穷途末路的人物，让他们在故事结束时变成彻头彻尾的另一个人。"（L37, L793）
    "不是所有的经历都一样。有明显的、容易代入的经历——我称之为'表面经历'，
    也有表面之下的、内在的、不易辨识的经历——我称之为'深度经历'。"（L795）
  key_distinction: |
    ≠ 字典义 "发生过的事 / 冒险 / 阅历"（"一个人去过 20 个国家旅行，年纪到了 50 岁，
      但这对我们却毫无触动"——L795）
    ≠ "事件"——事件是外部的，经历是人物对事件的内心认识与转化
    = 人物的内心变化轨迹；"在认识的基础上"的转化过程
    = 情节的引擎——"满足感来自骑行的过程，而不是终点处"（旅程 > 目的地，L791）
  why_it_matters: |
    下游所有"情节诊断 / 人物弧线"类 skill 若沿用字典义，会把"加更多事件 / 让人物去更多地方"
    当成加深情节，这是致命错误。正确做法是检查"人物对 X 的认识有没有改变"。
    "经历"是《情节》全书第一性概念，所有其他术语（悬念/冲突/上下文）都是为经历服务的。
  tags: [term, core-concept, chapter-4]
```

## g02 · 深度经历 (deep experience)

```yaml
- id: g02
  term: 深度经历
  type: framework
  source_chapter: 第 4 章
  author_definition: |
    "表面之下的、内在的、不易辨识的经历"（L795）。作者分三层，按深刻度递增：
      深度经历 1：认识他人（"我们整天都在听别人说话……但是很少真正听懂他们在说什么"——L797）
      深度经历 2：认识自我
      深度经历 3：在认识的基础上采取行动——"所有经历中最深刻的"
                  （"人物彻头彻尾地变成了另一个人，完全认不出来了——甚至连他自己都认不出自己"——L822）
  key_distinction: |
    ≠ 常识无此分层
    ≠ "认识" 自动等于 "深度"——认识若不触发行动，仍是未完成的深度经历（见 g09）
    = 三层递进结构，且"行动"在"认识"之上（这是反直觉的）
    = 衡量深度经历的标准是"人物是否变得认不出自己"
  why_it_matters: |
    下游"经历诊断 / 人物弧线" skill 必须用这三层做分层诊断，而不是笼统说"人物要有变化"。
    尤其第三层（行动）常被忽视——很多新手停在"人物认识到了"就以为完成了弧线，
    作者明确说没有行动就不算最深刻的经历。
  tags: [term, framework, chapter-4]
```

## g03 · 表面经历 (surface experience)

```yaml
- id: g03
  term: 表面经历
  type: framework
  source_chapter: 第 4 章
  author_definition: |
    "一种所有人都能识别的经历，一种传统的、社会普遍接受的成长或进步的标志，
    比如减掉 50 磅体重，或者在公司中晋升，或者一段新的恋情开花结果。"（L845）
    "下面列出七种常见的表面经历（按照它们改变人物生活的速度排序）：
    恋爱、物质、身体状况、友谊、知识、名望、家庭。"（L851 之后）
  key_distinction: |
    ≠ 常识视这七种为"人生成就"
    = 作者明确把它们归为"浅"——"这些经历很容易被误解成深度经历。它们不是。"（L845）
    = 表面经历价值在于"作用很大——它们是读者能够理解、代入、马上会提到的经历"
    = 关键用法是"作为引导人物走向深度经历的关键工具"（即作为深度经历的载体/外壳）
    = 讽刺点："深刻的、内心的经历经常看上去更不实际、不持久、虚无缥缈和容易改变；
      反之，大部分表面经历……被认为是更持久、更稳定的。人类的最大悲剧就在于我们让自己
      被这些表面经历蒙蔽，以为这些就是深度经历。"（L845）
  why_it_matters: |
    下游"爽点 / 升级流"类 skill 若不分表里，会把"升职/暴富/恋爱"本身当作情节满足感来源。
    作者澄清：这些是"读者能代入的快速外壳"，必须包裹深度经历才持久；
    若只有表面经历，作品读完即忘。
  tags: [term, framework, chapter-4]
```

## g04 · 认识-行动矛盾 (recognition vs. action contradiction)

```yaml
- id: g04
  term: 认识-行动矛盾
  type: technique
  source_chapter: 第 4 章（深度经历 3 小节末）
  author_definition: |
    "认识和行动之间是有可能存在矛盾的——事实上，这经常存在。不要急于解决这种矛盾……
    你可以利用甚至延长这种矛盾，从而创造出一种最深刻的紧张感。人物知道正确的行动是什么，
    但是不确定他是否要那样做。他与自己的内心交战。这种紧张感持续下去会变得令人无法忍受。"（L833）
    "这种内心冲突是数不清的神经官能症的来源，比如心理投射和偏执狂……
    一个人可能真的让自己生病，表现出生理上的症状……
    手掌流血或恶魔附身。"（L837）
  key_distinction: |
    ≠ 常识把"知道但做不到"视为人物弱点 / 情节bug
    = 作者把它定义为"最深刻的紧张感来源"，是深度冲突的特化发生器
    = 不应被急于解决——"延长"它才是技法
    = 极端化产物：神经官能症 / 道德困境 / 悲剧（如《罗密欧与朱丽叶》"行动永远无法达成"——L839）
  why_it_matters: |
    下游"冲突设计 / 文学性强化"类 skill 必须把它当独立技法。
    很多写手直觉上会让人物"想清楚就做"，反而扼杀了最深刻的张力。
    正确用法：让人物"知道 + 想做 + 开始做 + 太晚了"或"知道 + 做不到"，
    是悲剧和道德困境的核心机制。
  tags: [term, technique, chapter-4, conflict-source]
```

## g05 · 挥发性化合物 (volatile compound)

```yaml
- id: g05
  term: 挥发性化合物
  type: metaphor
  source_chapter: 第 4 章开篇（L793）
  frequency: 1 次（作者自创隐喻，全书核心开篇定义）
  author_definition: |
    "理想的人物像一种挥发性的化合物：不稳定、无法预期，
    在能治愈所有疾病的药物与大规模杀伤性武器之间只有一线之隔。
    这就是为什么斯坦利·埃尔金说他'只写那些穷途末路的人物'。
    我们必须记住，如果一开始没有不满和悬而未决，最后就不可能有满意和问题的解决。"（L793）
  key_distinction: |
    ≠ 常识的"圆形人物 / 复杂人物"——作者强调的是"不稳定 / 可被改变"的潜质
    ≠ "已经有变化"——而是"有变化的潜质"，是情节能够发生的前提条件
    = 一种临界状态——良药 ↔ 大规模杀伤性武器仅一线之隔（双向，即人物可被推向任一极）
    = 与"穷途末路的人物"互释——开篇就要在变化边缘
  why_it_matters: |
    下游"人物塑造 / 开篇诊断"类 skill 要用这个隐喻判断人物是否"可被情节推动"。
    检测问句：开篇时这个人物是否"不稳定"？是否处在某个临界点？
    若人物开篇就稳定平衡，后面所有经历都无效——这是新手最常见的死局。
  tags: [term, metaphor, chapter-4]
```

## g06 · 筹码 (stakes)

```yaml
- id: g06
  term: 筹码
  en: stakes
  type: technique
  source_chapter: 第 5 章（悬念第 2 式）、第 6 章（冲突第 5 式）
  frequency: 18 次
  author_definition: |
    "一个人出门扔垃圾也算是目标，但是这并不构成让我们心跳加速的悬念。
    制造悬念的方法之一是提高筹码。"（L1063）
    "提高目标的重要性是提高筹码的一种方法……重要性是相对的。"（L1075）
    提高筹码的三种机制：
      ① 提高目标对人物自身的重要性（出版合约对新人 vs 对职业作家）
      ② 提高目标对他人P747重要性（快递员送血袋——别人的命）
      ③ 加大危险（河里加鳄鱼 + 身后有军队）
  key_distinction: |
    ≠ 字典义 "赌注 / 押注金额"
    ≠ 固定量——作者强调它是"可被作家刻意提高"的放大器
    = 悬念与冲突的通用放大器（同一个目标，提高不达成代价，张力倍增）
    = 相对性是核心——"重要性是相对的"，必须绑定具体人物（亿万富翁 vs 挨饿艺术家）
    = 危险也相对——"必须是针对你的人物个人的危险"（超人不怕塌楼，怕氪石——L1081）
  why_it_matters: |
    下游"张力诊断 / 低张力场景修复"类 skill 的核心技法。
    错误用法：直接换更大事件。正确用法：保持事件不变，提高"不达成的代价"，
    且必须从"对人物的相对意义"入手，而非绝对金额/规模。
  tags: [term, technique, chapter-5, chapter-6, amplifier]
```

## g07 · 戏剧反讽 (dramatic irony)

```yaml
- id: g07
  term: 戏剧反讽
  en: dramatic irony
  type: technique
  source_chapter: 第 5 章（悬念第 8 式）、第 7 章（上下文视角）
  frequency: 13 次
  author_definition: |
    "'戏剧反讽'是指我们作为读者或观众，知道一些人物自己不知道的事——
    通常是会对他们造成影响的事。"（L1141）
    "对于人物来说没有悬念。对于鲨鱼也没有。这是一种特殊的悬念——只为我们设计的悬念。
    它非常有效。"（L1141）
    作者明确："在某种意义上，戏剧反讽是基于上下文的。"（L1453）
  key_distinction: |
    ≠ 字典义 "讽刺手法 / 反讽"——不包含讽刺意味
    ≠ 人物内心独白的讽刺
    = 信息不对称造成的"读者专属悬念"——人物无悬念，读者有悬念
    = 制造机制必须依赖上下文铺垫（午餐场景本身无悬念，加上"他被解雇了妻子不知"的上下文才反讽）
    = 可切换读者同情对象（同一场景改变"谁知道什么"会重定向同情——L1147）
  why_it_matters: |
    下游"悬念设计"类 skill 必须把它当独立发生器（不是目标 / 危险 / 滴答时钟的变种）。
    它是少数能让"无事发生"的场景充满张力的技法，且最适合延长（"优秀的作家会把这一幕
    尽可能延长……让晚餐充满错误的开始、暗示、干扰、分心和沉默"——L1143）。
  tags: [term, technique, chapter-5, chapter-7, suspense-generator]
```

## g08 · 上下文 (context)

```yaml
- id: g08
  term: 上下文
  en: context
  type: core-concept
  source_chapter: 第 7 章
  frequency: 55 次
  author_definition: |
    "写作是一支交响乐：没有什么是独立存在的，所有的元素都要根据它最终在多大程度上
    有助于（或有损于）其他元素来评判。"（L1419）
    "传统的编辑加工要求你字斟句酌，与此同时，上下文要求相反的东西：
    你必须从宏观上审视你的作品。这时你需要的是俯瞰的视角。"（L1421）
    覆盖维度：重复 / 人物 / 经历 / 时间 / 戏剧反讽 / 悬念 / 冲突 / 背景 / 节奏 / 进展 / 意义 / 篇幅分配
  key_distinction: |
    ≠ 字典义 "背景设定 / 语境"
    ≠ "世界观"（worldbuilding）——与设定无关
    = 宏观编辑视角（俯瞰视角 / bird's-eye view），是评判所有元素的尺子
    = 元素无绝对好坏，只看"对其他元素的助益/损害"——任何元素都是相对的
    = 核心 4 类编辑工作：
      ① 重复检测（"最常见的编辑工作"）
      ② 场景移植（同一场景换个位置意义全变）
      ③ 篇幅分配（"比任何其他东西都更能反映你的故事是关于什么的"）
      ④ 节奏 vs 进展（前者=展开速度，后者=有无取得阶段性结果）
  why_it_matters: |
    下游所有"宏观诊断 / 整体失衡"类 skill 必须用作者这个特定意义。
    若沿用字典义，skill 会去做"丰富背景设定"，而作者本意是"鸟瞰删重复 / 调篇幅"。
    特别注意：作者把"戏剧反讽"也归入上下文的产物（见 g07），这是常识读不到的关联。
  tags: [term, core-concept, chapter-7, macro-editing]
```

## g09 · 悬念 (suspense)

```yaml
- id: g09
  term: 悬念
  en: suspense
  type: core-concept
  source_chapter: 第 5 章
  frequency: 173 次
  author_definition: |
    "归根结底，悬念是关于预期的。它与某些我们期待之外的东西、某件还没有发生的事情有关。
    悬念是观看事件展开的过程：一旦受害者被谋杀，女人接受了求爱，悬念就消失了。
    但是当受害者被跟踪，女孩被追求，悬念则会若隐若现。
    简单地说，悬念就是创造和延长预期。"（L1063）
    "情绪是悬念的基本要素。"——希区柯克引语（L1047）
  key_distinction: |
    ≠ 字典义 "紧张刺激的桥段 / 悬而未决"
    ≠ "动作戏"——动作戏过多反而淹没悬念
    = 本质 = 预期（expectation）——制造它 + 延长它
    = 过程性——"一旦 X 发生，悬念就消失"，所以作家的工作是延长 X 不发生的时间
    = 比人物/经历/文笔都更能影响"即时阅读体验"——"只要有悬念，读者通常就会坚持看完作品"（L1047）
    = 与"经历"的关系：悬念应该是"经历的附属品"，不应成为目的本身
  why_it_matters: |
    下游"悬念设计器" skill 的核心定义。错误：把悬念等同于"刺激场景"。
    正确：问"读者在预期什么？这个预期在被制造还是被延长？"
    作者的 12 式技法清单本质都是"制造 / 延长预期"的不同机制。
  tags: [term, core-concept, chapter-5]
```

## g10 · 冲突 (conflict)

```yaml
- id: g10
  term: 冲突
  en: conflict
  type: core-concept
  source_chapter: 第 6 章
  frequency: 260 次（全书最高频）
  author_definition: |
    "一切冲突，无论是内在的还是外在的，都是与自我的战斗。"——弟子丸泰仙引语（L1233）
    "冲突有许多种功能：它要求读者选择立场……它制造裂痕然后为圆满解决铺平道路；
    它帮助制造悬念；它让作品具有方向感；它可以出乎意料从而让作品扑朔迷离。"（L1237）
    "冲突的本质 = 对抗"，最高形式 = 内心冲突（参见 g04 认识-行动矛盾）
  key_distinction: |
    ≠ 字典义 "打斗 / 争吵"
    ≠ 必须是显性的——"你作品中的每一个人物必须有与所有其他人物发生冲突的可能性，
      无论这种可能性是否变成现实……即使冲突从未爆发，观看两个可能发生冲突的人如何相处
      也是一件有意思的事。"（L1243）
    = 对抗（opposition），最高形式是内心冲突，"因为它无法被避免或解决"
    = 选择即冲突——"每一个选择都暗示着一种冲突"（L1235）
    = 可分为 13 种技法清单（人物/群体/被迫在一起/冲突的目标/提高筹码/权力斗争/竞争/时间/家庭/恋爱/工作/态度/内心冲突）
  why_it_matters: |
    下游"冲突设计器" skill 必须强调：
    ① 冲突可能性 > 冲突爆发（潜台词层）
    ② 内心冲突是最高形式而非降级形式
    ③ "提高筹码"是冲突章的技法之一，与悬念章的筹码技法同源（应被共用）
  tags: [term, core-concept, chapter-6]
```

## g11 · 多面性人物 (multifaceted character)

```yaml
- id: g11
  term: 多面性人物
  type: technique
  source_chapter: 第 3 章末（人物塑造）、第 8 章（超越）
  frequency: 14 次
  author_definition: |
    "在许多经受住时间考验的作品中，好人和坏人常常不那么黑白分明。在《教父》中，
    好人是杀人犯；事实上，唯一不肯涉足暴力的人物——弗雷多——是最不受我们尊重的。
    通常，在杰出的作品中，尽管人物有缺点，我们仍然爱他们；尽管人物有美德，我们仍然恨他们。"（L1569）
    "重点在于，在刻画多面性人物时，必须记住单面人物的优点……
    要让一个人物经得起冤枉，他必须首先值得同情。一份完美无瑕的纪录上留下一个污点；
    对于坏人，应该是在一长串背信弃义的历史上写下值得盛赞的光辉一笔。"（L739）
  key_distinction: |
    ≠ 字典义 "复杂人物 / 圆形人物"
    ≠ "道德暧昧"——作者明确警告："对于那些无法下定决心的作家……
      塑造'道德上暧昧不明'的人物可以是一个方便的借口。"（L733）
    ≠ "现实主义"——"认为现实主义高于一切的结果是，我们经常发现，
      留给我们主动去支持或反对一个人物的余地越来越小。"（L735）
    = 一种刻意的层次设计——让好人有坏面、坏人有好面，目的是产生"代入感" + "解读空间"（g12）
    = 必须建立在"值得同情"的底色上——"要让一个人物经得起冤枉，他必须首先值得同情"
  why_it_matters: |
    下游"人物设计 / 道德层次"类 skill 若用字典义，会写出"既不好也不坏"的无趣人物
    （作者最痛恨的结果——"介于值得同情与不值得同情之间……只是世俗和无趣的人"，L733）。
    正确用法：先让人物值得同情（单面基底），再叠加反差面。
  tags: [term, technique, chapter-3, chapter-8]
```

## g12 · 多维化环境 (multidimensional environment)

```yaml
- id: g12
  term: 多维化环境
  type: technique
  source_chapter: 第 8 章
  frequency: 6 次
  author_definition: |
    "我们还需要把他们放在情景和环境中，测试他们的性格，让他们的多面性显示出来。
    多维化的环境使得人物不需要刻意表现自己，同时多面性的人物使得环境不必在道德上是复杂的。
    二者可以结成一个强大的组合。"（L1573）
    "诀窍在于创造日常生活中可能发生的多维化环境，让人们可以代入。"（L1577）
    例：超市结账队伍 + 插队的老太太 + 你已迟到 15 分钟——你会叫住她吗？
  key_distinction: |
    ≠ "复杂场景 / 大场面"
    ≠ 必须是极端处境——作者明确：日常小事比大事更容易引起共鸣
    = 把问题抛给读者："在这样的情景下你会怎么做？"——因此环境必须可代入
    = 与"多面性人物"互为补足——强大环境 + 单面人物也能成立；
      多面人物 + 强大环境是"强大组合"
    = 功能：让人物的多面性"显示出来"（无需人物刻意表现）
  why_it_matters: |
    下游"场景设计 / 道德困境"类 skill 的核心技法。
    错误：堆极端事件。正确：找日常可代入的小情境（超市 / 家庭聚餐 / 通勤），
    利用"小事比大事更容易共鸣"的规律。
  tags: [term, technique, chapter-8]
```

## g13 · 解读空间 (space for interpretation)

```yaml
- id: g13
  term: 解读空间
  type: technique
  source_chapter: 第 8 章
  frequency: 14 次
  author_definition: |
    "多面性的人物和多维化的环境赋予了作品解读的空间……层次越多，需要解读的东西就越多。"（L1589）
    "解读的空间应该来自意义，而不是来自基本的事实和事件；如果读者在最基本的层面上
      不能理解发生了什么事，作品仅仅是令人困惑的，而不是暧昧不明的。
      这是许多新手作家会遇到的陷阱。"（L1587）
    "也有许多作家说他们的作品是'等待解读'的，这只是作为一个方便的借口，
      因为他们没有描绘出丰满的人物或事件……解读不能来自欠缺，而是来自意义的丰富。"（L1589）
  key_distinction: |
    ≠ "留白 / 模糊 / 不说清楚"——作者明确反对
    ≠ "开放式结局"
    = 必须来自"意义的丰富"（多层次的内涵），而非"事实的欠缺"
    = 20 个学生写 20 篇不同论文都言之成理——这是解读空间的诊断标志
    = 来自：多面性人物 + 多维化环境 + 多层面主题（《黑暗的心脏》同时是探险 / 心理学 / 社会学）
  why_it_matters: |
    下游"作品深度 / 经典化"类 skill 的关键诊断。
    错误：故意写模糊让读者猜。正确：让事实清楚，但意义多层。
    一条诊断问句：读者能复述发生了什么吗？如果不能，是令人困惑而非解读空间。
  tags: [term, technique, chapter-8]
```

## g14 · 阅读心理曲线 (reading psychology curve)

```yaml
- id: g14
  term: 阅读心理曲线
  type: framework
  source_chapter: 第 8 章
  author_definition: |
    "理想的作品可以让读者经历四个阶段：好奇 → 兴趣 → 需要 → 行动。"（L1655）
      阶段 1 · 好奇：每个读者都达到；源于营销 / 消息传播（"走到这一步是上天的礼物"）
      阶段 2 · 兴趣：不是所有读者达到；被人物或环境钩住，但未确定看完
      阶段 3 · 需要：更少作品达到；读者迫切想知道结局，且"不是转瞬即逝的需要"，
                    标志是"足够强大的人物和环境 + 足够多的经历 + 足够多悬而未决的问题 +
                    深刻的同情 + 彻底代入"
      阶段 4 · 行动：极少作品达到；读者读完把所读付诸行动（最高层次）
  key_distinction: |
    ≠ 常识无此模型
    = 作者明确用作"衡量作品影响力的诊断标尺"
    = 不是情绪曲线（不是起伏），而是投入深度阶梯（每层更难达到）
    = "需要"层明确诊断指标：经历够多 / 悬而未决够多 / 同情够深 / 代入够彻底——
      可作为可观测的检查清单
  why_it_matters: |
    下游"作品影响力诊断 / 弃书率分析"类 skill 的标尺。
    可以转化为评分模型：问 "我的作品激发了他人的好奇 / 兴趣 / 需要 / 行动吗？1-10 打分"。
    网文场景下："行动"层可降维理解为"催更 / 二刷 / 推荐"，仍保留四阶递进。
  tags: [term, framework, chapter-8, diagnostic]
```
