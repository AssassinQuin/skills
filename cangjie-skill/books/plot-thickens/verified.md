## 单元 1 → `suspense-designer`（悬念设计器）

**包含候选**: f06（12式上位生成器）+ f07（延长悬念）+ f08（戏剧反讽）+ f09（滴答时钟）+ f10（无能为力）+ p11/p12/p13 + ce06/ce17/ce18 + 案例 c22-c28
**一句话定位**: 给任何场景注入"让人放不下"的张力——悬念的本质是创造并**延长**预期，不是可怕事件本身。

- **V1 跨域 ✓**: 第5章（12式系统化）+ 第7章（"悬念太多淹没悬念"上下文约束）+ 跨 7 个电影案例（《超人》危险的相对性、《后窗》延长30秒、《北非谍影》秘密、《精神病患者》稀疏才有效）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question（书里没明说）: "一个管家第一次进新雇主宅邸送餐，这个平淡差事怎么写出悬念？"
  - derived_answer: 用 f10 无能为力（管家不能拒绝/不能问）+ f09 滴答时钟（必须在晚餐前完成且每次进宅都限时）+ f06 秘密（他撞见不该见的）+ f07 延长（每次欲言又止）。结论非平庸：悬念不在事件大小，在"保留什么+延长多久"。
- **V3 独特性 ✓**: "延长悬念 > 制造悬念""悬念是经历的附属品非目的""秘密不能独自承担重任"——均反直觉（常识是"制造大悬念""堆秘密"）。

## 单元 2 → `conflict-designer`（冲突设计器）

**包含候选**: f11（13式上位生成器）+ p14/p15/p16 + ce13 + 案例 c29-c31
**一句话定位**: 为两个人物/群体设计对抗——冲突的本质是"选择"背后的必然张力，且能让人物"显形"。

- **V1 跨域 ✓**: 第6章（13式）+ 第7章（冲突需上下文喘息）+ 案例《单身公寓》（被迫在一起）、《奥赛罗》（狡诈制造者）、《为黛西小姐开车》（想摆脱却不能）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "两个价值观不同但必须合作的同事，怎么让他们的冲突不沦为吵架？"
  - derived_answer: 用"冲突的目标"（两人目标都正当但互斥）+ "提高筹码"（项目成败关系晋升）+ "被迫在一起"（同组无法回避）。关键约束 p16：冲突要延长但不能永久，需阶段性解决给喘息。推出"非人格化冲突设计"——把对抗锚定在目标而非性格。
- **V3 独特性 ✓**: "冲突应从人物内生，环境只是放大器（ce13：靠极端环境造冲突=人物塑造失败）""每对人物必须有冲突潜能即使不爆发""冲突让人显形"——反直觉（常识是"避免冲突""冲突越激烈越好"）。

## 单元 3 → `inner-conflict`（内心冲突与知行矛盾）

**包含候选**: f12（内心冲突最高形式 + 投射论）+ f04（认识-行动矛盾紧张器）+ p09 + ce12 + 案例 c14/c15/c16
**一句话定位**: 制造最深刻的内心张力——人会制造外部冲突以逃避内心冲突；"知道该做却做不到"是最深刻的紧张感来源。

- **V1 跨域 ✓**: 第6章（内心冲突最高形式）+ 第4章（认识-行动矛盾）+ 案例《罪与罚》（自我认识）、《满洲候选人/发条橙》（被迫改变=最恐怖）、《汇流》（行动太晚的悲剧）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "一个真实里反复跟权威吵架的人，他的'问题'到底是什么？"
  - derived_answer（f12 投射论）: 反推他未解决的内心议题——他可能在用外部权威冲突逃避"我其实渴望被权威认可"的内心冲突。外部冲突越激烈→内心议题越严重。推出"外部冲突模式 = 内心议题的指纹"这一诊断法。
- **V3 独特性 ✓**: "外部冲突是内心冲突的投射，人无意识制造外部冲突以逃避内心""不要急于解决知行矛盾而要延长它""反派拒绝认识错误是心理自保（ce12）"——全部反直觉。

## 单元 4 → `experience-depth`（经历深度诊断）

**包含候选**: f02（深度三层）+ f03（表面7类生成器）+ f05（经历编织术）+ p03/p10 + ce10/ce11 + 案例 c14/c17/c18/c19/c20/c21
**一句话定位**: 诊断人物弧线是"真变了"还是"表面变了"——深度经历三层（认识他人→认识自我→在认识上行动），表面经历7类只是入口。

- **V1 跨域 ✓**: 第4章（全书哲学核心，论证最长）+ 案例《罪与罚》《逃出亚卡拉》（开头定义经历）《洛奇》（相互依存的经历）《教父/星球大战》（开启新纪元）。独立语境 ≥4。
- **V2 预测力 ✓**:
  - novel_question: "一个主角结尾当上了 CEO，读者却觉得'那又怎样'，问题出在哪？"
  - derived_answer（ce10 + f02）: 这是表面经历（名望）误当深度经历。诊断：人物获得了表面成就，但"认识他人→认识自我→在认识上行动"三层从未发生，内核信念未被挑战。修复：让 CEO 之路伴随一次"认识自己为何执着于权力"的深度经历。
- **V3 独特性 ✓**: "表面≠深度，人类最大悲剧是把表面当深度""停在认识他人层=觉醒了却重复旧模式""经历相互依存>单一，冲突的经历>和谐的经历"——反直觉且成体系。

## 单元 5 → `context-macro-edit`（上下文宏观编辑器）

**包含候选**: f13（俯瞰视角三步法）+ p17/p18/p20/p22 + p06（出场频率>时间）+ ce07/ce08 + 案例 c03/c04/c32/c33/c34/c35
**一句话定位**: 从宏观俯瞰作品——局部优秀的元素可能损害整体；最常见隐蔽问题是重复；节奏靠对比维持。

- **V1 跨域 ✓**: 第7章（专章）+ 作者编辑经验案例（删优美文字、作家两周后同意删场景）+《教父》（有意识重复=呼应 vs 无意识重复=削弱）《精神病患者》（稀疏才有效）《雨一直下》（背景对比）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "一部小说每章都有反转，读者却越读越无聊，为什么？"
  - derived_answer（p20 + ce06 + ce08）: 悬念太多淹没悬念——全程高潮让基准线消失，每个反转贬值。诊断：缺少"非悬念对比段"。修复：删减或压缩部分反转，插入喘息段，让保留的反转靠对比重获冲击。
- **V3 独特性 ✓**: "局部美可能损害整体，必须删""一口气读完专门找重复""上下文编辑要隔两周""出场频率>出场时间"——方法论体系，非纯常识。

## 单元 6 → `allocation-audit`（篇幅分配审计）

**包含候选**: f14（篇幅=作品真正主题）+ p19/p21 + p05（主次由重要性）+ ce09
**一句话定位**: 用篇幅/时间分配反推真实主题——别听作者说作品关于什么，看他花最多篇幅写什么。

- **V1 跨域 ✓**: 第7章意义节 + 第3章（p05 主次由重要性非篇幅）+《黑暗的心脏》（库尔茨篇幅少却是核心，反例佐证）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "一个人嘴上说'家庭最重要'，怎么判断他是否真心？"
  - derived_answer（f14 迁移到人生层）: 看他的时间/注意力分配——篇幅分配是意图的客观证据，比自述诚实。若他 80% 时间在工作、5% 在家庭，真实优先级就是工作。推出"分配即真实优先级"诊断。
- **V3 独特性 ✓**: "篇幅分配比任何宣言都更能反映作品关于什么""在没决定'关于什么'前就开始写=注定篇幅失衡"——反直觉（人倾向相信主观意图）。

## 单元 7 → `reading-psychology-curve`（阅读心理曲线诊断）

**包含候选**: f15（好奇→兴趣→需要→行动 4阶段）+ ce08 部分 + 案例 c41
**一句话定位**: 诊断作品/内容把受众停在哪个投入阶段——好奇（营销可达成）→兴趣→需要→行动（终极力量），越后越难。

- **V1 跨域 ✓**: 第8章 + 跨章节制（"需要"层要求足够强的代入与未解问题，回扣经历/悬念）+ 案例《刺杀肯尼迪》（激发给国会写信=行动层）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "一个产品 demo 能让投资人看完，但没人投钱，卡在哪？"
  - derived_answer（f15）: 停在"兴趣"层（不想离开但没决定看完/投入）。要到"需要"层需足够强的代入 + 未解问题；要到"行动"层需激发实际行为。诊断：demo 展示了功能（好奇/兴趣）但没创造"未解问题"或代入感。修复：留一个投资人必须解决的悬而未决。
- **V3 独特性 ✓**: 4阶段递进模型 + "大多数作品停在好奇/兴趣层""行动层是终极力量（煽动暴乱/写信）"——成体系的诊断标尺。

## 单元 8 → `interpretive-space`（解读空间设计）

**包含候选**: f16（多面性人物 + 多维化环境 = 解读空间）+ p23 + p28（间接激发感情）+ p29（时代细节+永恒）+ ce01/ce04/ce14/ce15 + 案例 c36-c40
**一句话定位**: 让作品经久不衰/可反复阅读——多面性人物+多维化环境→解读空间；关键约束：解读空间来自意义丰富，非事实欠缺。

- **V1 跨域 ✓**: 第8章（专节）+ 第3章（多面性人物、ce14/ce15 过度多面性的反例）+ 案例《教父》（好人=杀人犯）、《黑暗的心脏》（解读层次）、《歌厅》（时代细节+永恒）。独立语境 ≥3。
- **V2 预测力 ✓**:
  - novel_question: "读者反馈'看不懂'你的结尾，这是高级留白还是写砸了？"
  - derived_answer（p23 + ce04）: 区分"暧昧不明"（看懂了但意义多解=解读空间）vs"令人困惑"（连发生什么都不知道=失败）。若读者说不出发生了什么→是欠缺不是留白，需补事实；若读者懂事件但有多种解读→才是真正的解读空间。
- **V3 独特性 ✓**: "解读来自意义丰富非事实欠缺""多面性的前提是值得同情的锚点（ce14）""日常小困境比极端困境更易共鸣""感情不能直接追求要间接激发（p28）"——反直觉区分。
