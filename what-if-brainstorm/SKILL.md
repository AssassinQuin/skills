# "如果"问句头脑风暴（What-If）

## R — 原文 (Reading)

> "多数前提又源于如果：如果一个小男孩头脑发育过快，身体跟不上脑袋瓜的发展会怎样？……把'如果'问句清楚地写出来，这些问句能够放飞你的想象力，你可以看到之前没有看到的可能。"
>
> — 凯蒂·维兰德，第三章

---

## I — 方法论骨架 (Interpretation)

面对一个题材，别急着问"这个点子行不行"，而是故意**疯狂地**列出"如果 X 会怎样"的问句——不设限、不自我审查，多傻都要写下来。多数"如果"站不住脚也没关系，它们的价值不是被采纳，而是打开想象力的阀门、让你从全新角度切入。

即使某个想法行得通，也别停，继续追问"如果发生的是另一件事会怎样"。进阶玩法是**读者期待法**：列出"读者会期待什么"，再逐一决定满足还是颠覆，据此设计反转。

这是一个**发散**工具：只负责生成，不负责收敛。收敛是下一步（前提句）的事。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《守望黎明》的 13 条"如果"问句
- **问题**: 作者要写一部第三次十字军东征背景的历史小说，只有模糊设想。
- **方法论的使用**: 在提纲记事本首页写"如果"，疯狂列出 13 条（"如果安兰不是骑士会怎样""如果她没死会怎样""如果他是刺客会怎样"）。
- **结论**: 多数站不住脚，甚至可笑，但想象力的阀门打开了。
- **结果**: 小说从"复仇/救赎/爱情"的中世纪故事，蜕变为跌宕起伏、动人心弦的作品。

### 案例 2: 读者期待法设反转
- **问题**: 写完"如果"后，怎么安排转折？
- **方法论的使用**: 列出读者期待（"读者期待安兰本性善良"），再追问"如果他不善良呢？"。
- **结论**: 据此在读者预期之处埋张力、设反转。
- **结果**: 为小说找到了与传统之间的张力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户手里只有一个题材/一句话点子，不知道能写成什么。
2. 用户说"我有个人物经历，但不知道怎么编成故事"。
3. 用户卡在故事开头，想找多个可能的方向。
4. 用户想给一个已有故事找反转/悬念。

### 语言信号

- "帮我头脑风暴""这个点子能怎么发展""给我几个方向"
- "如果……会怎样？""还有什么可能""我只有个大概想法"
- "Expand this idea" / "brainstorm" / "what if"

### 与相邻 skill 的区分（初稿）

- 与 `premise-sentence` 的区别: 本 skill 是**发散**（生成大量可能性），前提句是**收敛**（压成一句话）。先发散后收敛。
- 与 `scene-map` 的区别: 本 skill 在"点子→故事"层面发散，scene-map 在"场景→情节"层面连点。

## E — 可执行步骤 (Execution)

1. **写下核心题材/点子**（一句话即可）。
   - 完成标准: 题材已具象成一句可被"如果"修饰的话。

2. **疯狂列 10+ 条"如果 X 会怎样"问句**。
   - 完成标准: 至少 10 条，含明显荒诞的（说明没自我审查）。
   - 判停条件: 若写到 20 条仍无新角度，换读者期待法（步骤 3）。

3. **列"读者会期待什么"，决定满足还是颠覆**。
   - 完成标准: 每个关键期待都有"满足/颠覆"的标注，颠覆处即反转。

4. **对行得通的想法继续追问**"如果发生的是另一件事会怎样"。
   - 完成标准: 至少一个想法被推到了第二层（"如果 A 和 B 都发生，那 C 会怎样"）。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要收敛/做决定时（发散工具，此时该用 premise-sentence）。
- 用户要的是严谨的逻辑推演，不是创意发散。
- 纯信息查询、事实核对——这与创意无关。

### 作者在书中警告的失败模式

- **头脑风暴时自我审查**：创造力是"羸弱多愁善感的花儿"，被挑剔的编辑（左脑）批评后迅速枯萎。
- **满足于"差不多"的点子**（拉里·布鲁克斯）：不写提纲的人很难意识到自己的点子有多平庸。

### 作者的盲点 / 时代局限

- "如果问句"极依赖作者的直觉与常识储备；对完全无经验的新手，可能问不出有质量的问题，需要先喂素材。

### 容易混淆的邻近方法论

- 与"梦想风暴/自由写作"的区分: 自由写作是"连续不断写下脑海一切"，"如果"问句是"有方向的发散问题"，两者互补。
